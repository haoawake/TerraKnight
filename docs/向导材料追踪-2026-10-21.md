# 向导材料追踪（2026-10-21）

## 使用方式

1. 和向导对话，打开“制作”，把材料放进向导槽。
2. 点击左侧列出的可合成物品，打开该物品的材料追踪面板。
3. 点击可制作的下位材料，继续查看其配方。面板显示已有量、所需量、制作站及环境条件；存在多条配方时，用左右按钮切换。
4. 点击没有下位配方的怪物掉落材料，自动打开图鉴并填入该材料名称。既能制作又能掉落的材料同时提供“看下位”和独立“图鉴”入口。
5. 使用图鉴上方“返回材料追踪”回到原路径；材料面板可返回上一级或直接返回目标。

商店材料显示具体出售者、阶段和已登记的月相条件；旅商材料注明随机出售。法术武器注明吸收对应法术后解锁。没有制作或怪物掉落记录的项目会显示获取说明，不伪造图鉴来源。

## 行为边界

- 查询为只读操作，不制造目标、不消耗或复制材料。关闭向导时，原材料仍由原有归还逻辑处理。
- 已有量包含背包、圣巢物品袋、向导槽与附近可供合成的箱子。光标上的其他材料不计入可用合成数量。
- 下位需求按每次配方产出量向上取整换算。这里展示完整目标的配方需求，不自动扣除玩家已持有的中间成品。
- 采用实际 `Recipes.All` 的全部真实配方；排除创造模式/基础购买所产生的虚拟购买条目。不会改写配方或合成条件。
- 掉落来源分类使用实际阶段 0–5、各敌人/地区的掉落表，不使用历史旧表冒充当前来源；没有调整掉落率、数量、权重或来源。
- 跳转图鉴会清除上一次的地区/阶段过滤，沿用存档当前阶段和原有发现/击败解锁规则。未解锁的资料不会因材料追踪而自动解锁。
- 木材/平台等转换配方返回已有路径节点，避免无限循环。路径有最大深度保护。
- 更换向导槽中的材料或关闭背包会结束当前追踪；本次没有实现跨会话固定追踪清单。
- 查询在本机完成，不向其他玩家发送操作。
