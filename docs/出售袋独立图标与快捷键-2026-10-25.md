# 自动出售袋图标与快捷出售

自动出售袋改用独立透明 32×32 像素图标：深色钱袋、金币与出售箭头。只替换该模组物品的资源引用，原版草药袋贴图不变。图标由内置 imagegen 生成，原图和完整提示词保存在 `artifacts/auto-sell-bag-art/`；游戏资源为 `src/TerraKnight/Resources/auto_sell_bag.png`。

| 打开的面板 | 操作 | 效果 |
|---|---|---|
| 掉落物黑名单 | 左键或 Shift＋左键点背包物品 | 记录类型，不消耗当前物品；之后拾取时自动出售 |
| 自动出售袋 | Shift＋左键点背包物品 | 加入名单并当场卖掉整堆，沿用原有正售价限制 |
| 上述任一面板 | Ctrl＋左键点背包物品 | 仅出售当前整堆，不改变名单；可在快捷商店按原价买回 |

Ctrl 出售复用快捷商店的售价、交易记录与买回机制。收藏物、货币、骨钉和梦之钉受到保护；鼠标拿着物品时不交换或出售；关闭两面板后 Ctrl 恢复普通垃圾桶行为。同时修复了关键工具被“圣巢物品可出售”例外放行的问题，其他可回收的圣巢物品维持原有规则。
