# 空洞骑士原版护符能力（1.5.12620）

整理原版 40 个护符的凹槽消耗、效果数值、获得方式和护符之间的联动，作为空洞泰拉升级护符的参照。

**数据来源**
- 名称和描述来自游戏语言表（`resources.assets` 的 `ZH_UI` / `EN_UI`）。
- 凹槽消耗来自 `PlayerData` 的默认值。
- 跑速、冷却、无敌时间等数值来自骑士预制体上 `HeroController` 的序列化字段。
- 效果逻辑来自反编译的 `HeroController`、`NailSlash`、`HealthManager`，以及骑士身上的 PlayMaker 状态机。
- 获得场景来自扫描各场景文件里的 `gotCharm_N`。

标注 **〔资料〕** 的数值来自社区资料，没有在游戏文件里逐项核实；其余数值都直接取自游戏文件。

---

## 基本规则

- **凹槽**：新存档 3 个（`charmSlots = 3`），最多 11 个。另外 8 个来自萨鲁巴出售（4 个）、菌类荒地的蘑菇食人魔、雾之峡谷、斗兽场勇士试炼和格林剧团〔资料〕。
- **装备**：只能在长椅上更换。
- **护符过载**：凹槽不够时仍可多装一个，过载状态下受到的伤害 ×2（`HeroController`：`TakeHealth(damageAmount * 2)`）。
- **易碎护符**：易碎心脏、易碎贪婪、易碎力量在死亡时破碎，可在食腿者处修复，或在戴薇娜处换成不会碎的坚固版本。

## 护符联动

以下组合都能在游戏文件里找到对应判断，具体数值另有标注的除外。

**骨钉**
- **修长之钉 + 骄傲印记**：骨钉范围 ×1.4（单戴分别为 ×1.15、×1.25）。
- **易碎/坚固力量 + 亡者之怒**：力量把斩击基础伤害设为骨钉伤害 ×1.5（`Set Slash Damage`）。亡者之怒再把每段斩击的伤害倍率设为 1.75（`Fury` 状态机写 `damages_enemy.Multiplier`）。两者相乘，共 ×2.625。
- **蜕变挽歌 + 骄傲印记**：光束高度 ×1.35。
- **蜕变挽歌 + 亡者之怒**：1 格面具时射出怒焰光束。
- **蜕变挽歌 + 乔尼的祝福**：坐长椅后持续射出光束，受伤后停止（`joniBeam`）。
- **锋利之影 + 冲刺大师**：锋利之影的伤害 ×1.5（`Set Sharp Shadow Damage` 的 MASTER 分支）。

**移动**
- **飞毛腿 + 冲刺大师**：跑速 11.5。
- **编织者之歌 + 飞毛腿**：编织者幼体移动更快。

**灵魂**
- **幼虫之歌 + 蜕变挽歌**：受伤得灵魂 15 → 25。
- **编织者之歌 + 幼虫之歌**：幼体命中也给灵魂（3 点〔资料〕）。

**法术**
- **防御者纹章 + 吸虫之巢**：小吸虫变成一只大粪吸虫（`Spell Fluke Dung`）。
- **萨满之石 + 吸虫之巢**：吸虫伤害提高，粪吸虫同样生效。

**聚集**
- **防御者纹章 + 蘑菇孢子**：孢子云换成粪雾。
- **深度聚集 + 蘑菇孢子**：孢子云 / 粪雾范围变大。

**同伴**
- **防御者纹章 + 发光子宫**：孵出粪幼崽〔资料〕。
- **梦之盾 + 舞梦者**：梦之盾的 `Shield Hit` 状态机单独判断了舞梦者，同戴时盾被打碎后重生更快〔效果资料〕。

**生命**
- **乔尼的祝福 + 易碎心脏**：生命血按加了易碎心脏后的面具上限 ×1.4 计算。
- **亡者之怒 + 乔尼的祝福**：亡者之怒的状态机单独判断了乔尼的祝福，同戴时的触发条件另有处理。

## 空洞泰拉的现状

以下内容来自当前代码，作为规划升级的起点。

**护符栏不可用**
- 原版背包键交给了泰拉背包（`PlayerHooks.NoKnightInventory`），玩家打不开原版护符菜单。
- 捡到护符只会记录 `gotCharm_N`，护符本身没有效果。

**已单独处理的护符**
- **飞毛腿**：获得后给赫尔墨斯靴（`PlayerHooks.AbilityItems`）。
- **国王之魂 / 虚空之心**：作为圣巢背包里的物品，携带即生效，用于打开出生地的门和结局判断（`Items/HkItems.cs`）。
- **格林之子**：放进宠物栏召唤，算作佩戴，格林剧团仪式和地图火焰照原版判断（`Items/HkItems.cs`）。

**护符依赖的原版系统**

| 原版系统 | 模组里的状态 | 相关护符 |
|---|---|---|
| 骨钉斩击 | 手持骨钉物品时照原版攻击（`NailItem`） | 6、13、14、15、18、25、32、35 |

## 复核方法

所用脚本放在会话草稿目录 `D:\ClaudeTemp\claude\e------------github-----projects---\055506a9-dff8-4161-8087-7ef7ac29986e\scratchpad\charms\`，只读取游戏数据目录里的固定文件：

- `extract.py`：从语言表取名称、描述，从反编译的 PlayerData 取凹槽消耗，结果在 `charms.json`。
- `hero_values.py`：从 `resources.assets` 里骑士预制体的 HeroController 读取序列化数值。
- `fsm_charm_refs.py`、`fsm_dump.py`、`fsm_vars.py`：列出引用护符的状态机、导出字符串，以及读取具名变量（例如 `MP Cost = 33`、`Time Per MP Drain UnCH = 0.027`、发光子宫的 `Soul Cost = 8`、`Hatch Time = 4`、`Hatchling Max = 4`）。
- `charm_scenes.py`：扫描各场景文件里的 `gotCharm_N`，得到获得场景。

标注〔资料〕的项目如果要用作平衡依据，可以用 `fsm_vars.py` 和 `fsm_dump.py` 在对应状态机里继续核实。
