# 紫晶属性观测仪与 Boss 首杀成长

## 使用方式

打开背包，原四个快捷按钮旁新增紫晶观测仪图标。点击展开属性面板；右上角 × 关闭。面板含「综合属性」「手持武器」「生效装备」「更多属性与效果」四页，支持滚轮与上一页 / 下一页，关闭背包时一并关闭。

读数来自当前装备、共享装备、词缀、锻造、套装、药水与动态增益的实际计算路径。武器页读取当前手持物品；弓枪按当前将使用的弹药计入伤害，缺少弹药时明确说明。空手省略武器伤害。伤害为武器面板计算值，不把敌人防御、暴击结果或命中时才触发的特殊效果伪装成固定数字。

综合页显示生命 / 上限、护盾、魔力 / 上限、含锻造防御、防御抵消量、常驻免伤、当前敌袭的总比例免伤、护甲临时层数、四职业增伤、首杀奖励、已占 / 最大召唤栏、哨兵数量、再生与药水病等。额外效果页显示攻速、暴击加成、弹药类型倍率、鞭子范围、移动、飞行、挖掘、钓鱼、当前 Buff / Debuff，以及生效装备的完整效果说明。

日耀与甲虫减伤使用只读预览，查看面板不会消耗护盾或层数。长内容可将鼠标停在对应行查看完整文字。

提供的 PNG 逐字节复制到 `src/TerraKnight/Resources/hk_UtilityStats.png`，通过绘制 UV 选取可见区域，保持原始素材文件不变。

## 首杀成长规则

- 每种独立 Boss 完成整场战斗后，永久增加 **0.5 个百分点免伤**和**0.5 个百分点近战、远程、魔法、召唤增伤**。
- 线性累加到现有装备加成；重复击杀与同一 Boss 的普通神居重赛不重复奖励。
- 沿用现有 48 场 Boss 圣物身份映射，额外区分共用图鉴的暴怒守卫、战斗姐妹、有翼诺斯克、无上辐光；不需要真的掉落或拾取圣物，所有难度均生效。
- 48 场全部首杀后，永久奖励分别为 +24 个百分点。
- 接入 `Bestiary.Credit` 的整场战斗结算，位于多体 / 阶段完成判定之后。特殊死亡与联机本地胜利信用沿用现有结算路径。
- 个人首杀身份写入已持久化的角色授予记录。读档直接恢复，切配装与反复重赛不增加次数。
- 老存档按已有有效 Boss 击杀记录一次补计。四种共用图鉴的特殊形态无法从历史击杀数字可靠区分，不猜测旧首杀；更新后首次独立记录时计入。
