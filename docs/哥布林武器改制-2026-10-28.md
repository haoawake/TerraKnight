# 哥布林：武器改制

与哥布林工匠对话，选择「武器改制」，放入具有新旧两套行为的武器，敲击原生锤子图标即可在原版和新版之间转换。界面会先显示目标版本与价格，改制必定成功。转换只改变放入的那一把，不改变世界默认模式或其他同名武器。

词缀、锻造等级、收藏标记与数量保留；关闭界面或保存时武器按原有哥布林服务路径返还背包，装不下则落在玩家脚下。连续敲击有 0.35 秒间隔，防止一次误触立刻转换回去。不具备另一套行为的材料、饰品、召唤杖、工具等不接受改制。

## 价格

以武器自身的基础阶段、基础稀有度计价，不随玩家当前阶段回退，也不因重铸词缀和锻造增加价格。

| 武器阶段 | 基础价（吉欧） |
| --- | ---: |
| 0 | 250 |
| 1 | 450 |
| 2 | 800 |
| 3 | 1300 |
| 4 | 2000 |
| 5 | 3000 |

在此基础上，每级基础稀有度加 75 吉欧（按 0～11 级计算），单次 250～3825 吉欧。界面显示的就是本次实际费用，资金不足不扣款、不改变武器。

## 数据与行为

`ItemStack.WeaponVersion`：0 跟随世界默认，1 固定原版，2 固定新版。旧物品缺少字段时继续使用原先的世界默认。物品定义、近战动作、右键技艺、法师动作、射手动作、鞭子等读取单件武器的版本。

弹幕与延迟发射会记录发射时的有效版本，更新和绘制时恢复相应上下文，切换手持武器不会改变已发射弹幕。武器版本随存档物品、个人银行、箱子、落地物品和联机物品请求传递。家园合堆仓库和排序将不同版本分开保留，避免误合并。

弹幕联机快照新增版本信息，网络协议由 net15 升为 net16；联机玩家须使用同一新版。完整双客户端联机未实测。
