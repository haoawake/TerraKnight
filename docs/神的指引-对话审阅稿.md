# 神的指引：对话稿

状态：已写入游戏（`Items/BossGuideLines.cs` 的台词表，`Items/BossGuide.cs` 的播报）。本文的台词表由台词表生成，两边一致。

## 世界观与口吻

玩家是泰拉瑞亚世界的冒险者。在一次旧日军团入侵中，埃特尼亚传送门发生异变，将玩家和随身装备卷入圣巢。这里的虫族、灵魂与梦境有自己的规则；玩家保留锻造、建造与四职业战斗的能力，却不知道怎样回家。

神的身份不揭露，字幕署名「门外之声」。它自称能感知世界间的裂隙，却始终不说为什么把玩家带来；它的指引帮玩家找到下一个对手，不能据此认定它就是辐光、白王或泰拉瑞亚的某位既有人物。

语气短、冷静、带具体地标意象。台词不直接说出 Boss 的名字，靠地点和特征指路；下文表格里的 Boss 名只供作者对照。

## 播报规则

- **是否听从**：新建存档时选完难度，会弹出“神的指引”选择框，问是否听从它的指引；选“听从”才会播报，选“拒绝”之后不再有任何台词。随时可以在“泰拉瑞亚设置 → 神的指引”里开启或关闭，只对当前存档生效。更新前的旧存档默认关闭，也可以在那里开启。开启时如果已经打过 Boss，门外之声先说「你终于肯听了。」，再指向还没打过的第一场；还没打过任何 Boss 就从开场对白开始。关闭时正在说的和还没说的台词都作废。
- **什么时候说**：48 场战斗（44 个 Boss 条目，加上与本体共用图鉴记录的暴怒守卫、战斗姐妹、有翼诺斯克、无上辐光）各在第一次完整打赢时说一次，和首杀属性成长按同一份记录（`BossMastery`）。重复召唤、神居重赛、多体 Boss 的单个身体倒下都不说。
- **等战斗演完**：首领的死亡演出和战利品结算完成（`BossLootTiming`）、首领自己的对话结束（原版对话框收起，对话播报的台词播完）、玩家拿回控制权，并且这些状态持续安静 3 秒后才开口；说到一半如果游戏自己的对话或过场开始，门外之声停下，结束后把那一句重说。
- **结局与读档**：还没说出口的首胜记在存档里（如空洞骑士、辐光击败后直接进结局动画和标题画面），下次读档进入游戏后照常补说；指路按说话时的进度计算。
- **怎么显示**：屏幕上方居中的字幕，上面一行是说话人（「门外之声」或玩家名），同时写进左下角聊天框，按 Enter 打开聊天框可以回看。每句停留 3~9 秒，按字数定。联机时每个玩家按自己的首杀记录播报，不占用控制。
- **一句话的组成**：首胜台词（越级时换成越级台词）＋（必要时一句过渡）＋指向台词。

### 指向谁

48 场战斗按阶段分组（阶段取自图鉴的阶段；四个共用记录的强化形态各定一个阶段），阶段内按路线顺序排列（下文各表的顺序）。打赢一场阶段 N 的战斗后：

1. 先指向**同阶段**里排在最前、还没打过的那一场；
2. 同阶段全部打完，再指向**阶段 N 之后**还没打过的第一场，先说过渡句「这一程的对手，都已倒在你身后。」；
3. 阶段 N 及之后都打完、只剩更早阶段没打时，指回**身后**还没打过的第一场，先说「再往前已无人拦路，你身后却还留着没算完的账。」；
4. 48 场全部打完，说收束对白。

### 跳关与越级

- **跳关**：还有前面阶段没打就先打赢了后面阶段的 Boss，照常播报首胜台词，指路照上面的规则从这个 Boss 的阶段往后走。
- **越级**：打赢一场时，如果之前已经打赢过更后面阶段的 Boss（说明玩家是回头清理），这一场说**越级台词**，指路同样从它的阶段开始：先指同阶段剩下的，再往后。阶段 5 之后没有更高阶段，阶段 5 的战斗没有越级台词。
- **旧存档**：更新前已有的首杀照样算作“已打过”，用于指路和越级判断；更新前的首杀不补播。

## 开场对白

**触发：听从指引、存档里还没有任何首胜时，进入游戏、恢复控制 3 秒后**（新存档就是从旧日军团的传送门走出之后），每个存档一次。

**玩家：**「门后应该是军团的营地……这是什么地方？」

**玩家：**「没有守卫，没有水晶。连天空都像被石头封住了。」

**门外之声：**「你的世界仍在门的另一边。只是，来路已经不肯认你。」

**玩家：**「是你把我带来的？」

**门外之声：**「先活下去。你会在这里找到炉火、矿石，还有足够多不愿让路的东西。」

**玩家：**「我问的是，怎么回去。」

**门外之声：**「（第一场还没打过的战斗的指向台词）让它倒下，我便能把你听得更清楚一点。」

新存档里这一句是：「十字交错的旧路中央，一副不合身的重甲正替它的主人守门。让它倒下，我便能把你听得更清楚一点。」

## 收束对白

**触发：48 场战斗全部打赢后，接在最后一场的首胜台词之后。**

**玩家：**「你说，打倒它们就能找到回去的路。」

**门外之声：**「我说过，你会找到门。我从未替你选过门的另一边。」

**玩家：**「你一直在借我的手，打开这里。」

**门外之声：**「也许。也许一扇关闭太久的门，只能等一个不属于这里的人来推。」

**玩家：**「那就由我决定，什么能跟着我回去。」

收束只确定语气与悬念，不新增结局、跨世界关卡或强制传送。

## 示例

- 新存档先打假骑士：「甲壳碎了，里面的恐惧却比你想的更小。旧路东侧有一间安静的巢室，一位母亲在沉睡里护着满腹的孩子。」（同阶段还剩格鲁兹之母和毛里克，指向格鲁兹之母）
- 阶段 0 的最后一场打完（毛里克）：「独处太久，连呼唤也会长出利齿。这一程的对手，都已倒在你身后。往旧路西边的绿意里去；有人用一根针，替整座废墟试探来客。」
- 跳关先打守望者骑士（阶段 3），之后照常指向阶段 3 的收藏家；回头再打假骑士时：「从更深处回来的人才看得清：那副重甲从来只是空心的虚张声势。旧路东侧有一间安静的巢室，一位母亲在沉睡里护着满腹的孩子。」（越级台词，然后指向阶段 0 剩下的格鲁兹之母）

## 机制边界

- 属性成长独立于台词：每个独立 Boss 首杀永久增加 0.5 个百分点免伤和四职业增伤（`docs/属性观测仪与Boss首杀成长.md`）。台词不发额外奖励。
- 指向台词只提示地点和特征；能否进入某场战斗看实际的入口条件，也可以用 Boss 召唤物直达。
