# 全局衣柜

衣柜收藏属于当前角色存档，同一存档里所有地区的梳妆台共用。不需要先制作或放置家具，时装也会自动收纳。

- 单人打怪掉出的时装直接收纳；联机共享掉落由实际拾取者收纳，个人奖励直接收纳。
- 第一次获得一件时装会永久解锁这一件；重复获得的件数按物品原本售价自动结算。制作、购买和其他获得途径使用相同规则。
- 右键任意地区梳妆台打开衣柜。Shift＋右键仍能打开旧的 40 格储物抽屉。
- 套装按原有套装关系分组，每套都有头、身、脚三个泰拉瑞亚原生物品格；缺少的部位留空。纯外观饰品在套装下面单列。
- 标题、说明、套装名、地区按钮、部位文字、翻页按钮和页码均居中。套装本身不存在的部件显示纯黑格子，不显示文字；部件存在但尚未获取时显示“头／身／脚”；已获取时显示物品图标。
- 左侧可筛选 24 个地区。掉落时装按照携带该套装的敌人栖息地归类；地区制作时装按材料所属地区归类。
- 左键已解锁部件，取一件到鼠标；右键头、身、脚部件直接穿到对应时装栏。取用不消耗收藏，可以混搭。
- 取出的副本价值为零，不能作为合成材料或微光转化，丢弃即消失。返回背包、向导、储物箱及存档不会变回有价值的原件。
- 旧存档已有的获取记录会补入收藏。包内和私人仓库里的原件自动收纳；已穿着的时装保持穿着，改为衣柜副本。旧储物抽屉中的物品仍可通过原入口取回。
