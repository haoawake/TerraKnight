# 武器特效不透明度（2026-10-21）

位置：背包 → 泰拉瑞亚设置 → 界面 → 武器特效不透明度。

范围 0%～100%，默认 100%。0% 隐藏，100% 保持原样；拖动立即生效，自动写入本机配置，重新打开设置或启动游戏后保留。旁边提供恢复特效 100% 的按钮。

## 覆盖的绘制入口

- FxBatch 的战斗绘制：挥砍、鞭子、弹幕、光束、命中特效、拖尾、爆炸、白波/黑波及白吼/黑吼等自定义技能。
- 仆从和哨兵的绘制，以及本机显示的其他玩家弹幕与召唤物，沿用相同的本地不透明度。宠物、人物、地图和城镇居民不通过战斗绘制作用域减淡。
- TerraParticles 的普通、叠加发光粒子及碎片；粒子本身的生命周期和同步不变。
- 天顶剑独立绘制的剑体、光层、残影、星芒和网格拖尾。
- 骨钉技艺及人物原版攻击/能力特效，暗影冲刺生成的爆发、圆环和烟雾；人物的装备/闪避残影也受控。
- 护甲环绕特效、护符技能波纹、爆炸短暂光晕和战斗绘制中的发光。

人物本体、手持物品本体、家具、背景、界面和伤害数字保持各自原有显示。声音、镜头震动不属于不透明度调节。原版原生效果只注册人物攻击/效果层及明确生成的能力效果，不扫描或隐藏整个场景的敌人和环境。

## 实现要点

配置键：`[Video] WeaponEffectsOpacity`，存储为 0～1，默认 1；异常值回到正常显示，越界值限制在合法范围。

FxBatch 在拆分普通透明层和叠加发光层之前缩放预乘颜色，保证 alpha 为 0 的叠加发光也能减淡。独立粒子按其混合方式分别缩放 alpha 或已预乘的 RGB。原生攻击效果仅在相机绘制期间应用颜色/材质属性或零值隐藏，绘制后恢复；不永久改动动画颜色和池化对象，不逐帧累乘颜色。

设置只用于本机显示，不写入攻击伤害、碰撞、命中范围、弹幕/粒子生命周期或网络数据。即使 0%，攻击仍照常模拟。
