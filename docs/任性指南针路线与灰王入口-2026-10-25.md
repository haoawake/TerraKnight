# 任性指南针全屏路线与灰色王子左特入口

## 修复

全屏地图之前只绘制目标图标、人物附近及屏幕边缘的直线方向箭头，小地图和透明叠加地图才调用房间出口导航。全屏地图现在使用同一条金色流动光点路线，并标出跨房间/跨地图层的门；移除全屏指南针的直线箭头显示，增加底部目标和行动提示。

路线按房间出口连接，不是逐格寻路；页面提示明确说明不能据此穿墙。目标位于另一层时，提示从门换层或切换浅层/深层查看。

灰色王子左特按原生进度选择当前任务地点：

1. 尚未从复仇蝇之王手中救下左特：苍绿之径。
2. 尚未在深邃巢穴救出左特：蛛网囚困地点。
3. 尚未救出布蕾塔：真菌荒地。
4. 尚未在勇士的试炼击败左特：愚人斗兽场。
5. 前置完成：布蕾塔家的地下室，用梦之钉攻击左特雕像进入梦境。屋外左特不是入口。

左特死亡时不再选择这条无法开启的原生梦境路线；若只剩此目标，显示明确原因。Boss 向导原先“在床边敲梦之钉”的文字同步修正为地下室雕像。
