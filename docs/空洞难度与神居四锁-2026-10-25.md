# 空洞难度与神居四锁

空洞难度从角色生存能力增加压力：生命上限为正常值的 85%，治疗药水冷却为正常值的 120%。保留已有大师数值和原生面具数量增伤；敌人技能、前摇、攻击间隔、位移幅度和动画速度沿用大师，Boss 硬直也使用大师规则，不再有空洞专属全程霸体。

空洞追加环境伤害规则：每次有效环境命中造成当前生命上限的 50% 伤害，奇数向上取整，生命上限本身不变。按生命锁结算后的上限计算：425 上限扣 213，350 上限扣 175。防御、耐力减伤和亡者毛衣不会降低该固定伤害；原有免疫、受伤无敌时间和护盾继续生效。覆盖尖刺、荆棘、酸液、原生及人工岩浆、深坑、摔落、落石、陨石灼热地块和错误锤击祭坛的反伤。陨石接触伤害经过正常受伤无敌时间，避免每帧重复扣半血。敌人攻击和中毒等后续状态伤害保持原有规则；大师及以下环境伤害保持原样。

## 神居四锁

| 锁 | 效果 |
| --- | --- |
| 武器 | 最终伤害为 85%，覆盖各职业、召唤物和持续伤害 |
| 生命 | 生命上限为正常值的 70% |
| 饰品 | 饰品属性、词缀属性与技能失效，保留冲刺和多段跳，翅膀不生效；护甲和套装效果继续生效 |
| 恢复 | 战斗中禁用自然恢复和吸血，药水治疗量为 70%；休息长椅和神居温泉可恢复，泰拉蓝量不受限制 |

四锁取自原生万神殿开关，仅在万神殿序列的神居场景生效。离开后恢复，不删除装备或修改装备定义。空洞与生命锁叠加时取 70%，不会变成 59.5%。饰品锁保留普通冲刺、暗影冲刺、水晶冲刺与盾牌冲刺本身，以及云朵瓶、沙暴瓶、暴雪瓶、放屁瓶、海啸瓶这类多段跳（含合成后的气球）；翅膀不生效，复合饰品的其他属性和技能关闭。

## 收益

- 空洞：在大师原有收益基础上，敌人材料与吉欧额外 ×1.4；材料数量使用随机补足小数的方式，避免小堆叠收益被取整吃掉。
- 通关材料：武器、生命、恢复锁分别 +20%，饰品锁 +40%；全四锁额外 +50%，合计 ×2.5。
- 空洞全四锁通关材料合计 ×3.5。
- 材料仍按当前阶段和门数发放，不越级加入装备，不增加武器/饰品掉率。普通挑战保持原有通关材料。
