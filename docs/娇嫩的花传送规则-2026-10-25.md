# 娇嫩的花传送规则

携带完整的娇嫩的花时可以使用传送；通过原有条件检查、开始执行传送时，花会损毁。不会因为花而禁止传送，也不会绕过传送本来的进度、物品、队伍或角色状态检查。无效队友、缺少回城目标、无法落脚的闪现等未被接受的请求不会损花。

接入入口：晶塔，回城药水和镜子，虫洞药水及队友传送，返回药水和返回传送门，随机传送药水，混沌/和谐传送杖，暗影闪现，首领印记及联机跟随，斗兽场召唤物。

损毁设置原生 `xunFlowerBroken` 标记，并立即同步移除背包、圣巢背包、快捷栏和鼠标上的完整花，显示“娇嫩的花在传送中损毁了”。同一朵花只损毁一次。正常步行换房间不触发此规则；原生梦之门及其他原生交通继续使用游戏自己的规则。

旧的 `DelicateFlower.Blocks` 和 `Refusal` 拦截已移除。测试沿用 `flowerblock` 套件名，但内容已经改为验证“可以传送并损花”，而不是验证禁止传送。
