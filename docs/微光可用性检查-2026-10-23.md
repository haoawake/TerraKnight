# 微光可用性检查（2026-10-23）

## 使用方式与范围

微光目前是遗忘十字路温泉 `Crossroads_30` 的固定区域，不是可用桶搬运的液体。站在池边向池中抛出物品，支持转化的物品连续浸泡约 90 个逻辑帧（1.5 秒）后转化或拆解；产物上浮并可捡回。产物不会在同一次浸泡中连续转化，捡回后重新抛出才能继续。

直接转化保持整堆数量；拆解只消耗完整批次，余数保留；炼金配方回收带有原版的随机损耗。混沌传送杖转和谐传送杖需要阶段 5。微光不替代温泉对玩家的原有作用。

**联机共享掉落物目前不支持微光转化。** `WorldItemsShimmer.ShimmerTick` 只允许 `NetId == null` 的物品进入转化，`NetApply` 创建的共享物品在池中也不会变化。本轮验证了这个入口及共享记录的实际物品模拟，没有执行双客户端联机测试，也没有把这一限制记作“联机功能通过”。

## 发现并修复的问题

新增的替代材料配方排在配方表后面，原来的拆解选择逻辑默认取最后一个，导致火把拆解返回灰烬木，工作台等物品也可能选择到替代材料。

现在展开的替代材料配方带有 `IngredientAlternative` 标记，不会覆盖已存在的默认拆解配方；阶段系统复制配方时也保留此标记。由原版数据明确指定的拆解配方仍优先；之前完全没有配方的物品仍能使用新增配方拆解。替代材料的正常合成注册保留。

涉及 `Items/Recipes.cs`、`Items/Shimmer.cs`、`Items/ProgressionRecipes.cs`。测试入口为 `DevAutoTestShimmerAudit.cs`，套件 `shimmeraudit`。
