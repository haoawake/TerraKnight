## 原理

- 只运行空洞骑士一个游戏，通过 BepInEx 插件把泰拉瑞亚的系统用原生代码实现进去。
- 泰拉瑞亚的贴图和音效**在运行时从你自己电脑上装的泰拉瑞亚里读取**，mod 本身不带任何泰拉瑞亚素材，所以两款游戏都需要拥有并安装。
- 地形：读取场景原本的 tk2d 碰撞轮廓，栅格化成格子，换成分块的复合碰撞体。挖开的地方用 SpriteMask 把空洞骑士的地面美术抠掉，黑色填充也改由 mod 自己按格子画。
- 无缝地图：进入一个场景后，在后台把它各个门后面的场景叠加载入（真的场景，脚本、敌人都在跑），在任何脚本启动之前把整个场景挪到门的另一边（两个门重合；左右门还会对齐门下的地面）。门线这边归本场景，那边归隔壁。隔壁场景的进场设置（音乐、调色、黑暗程度、区域标题、影子）先压着，玩家真正走进去时才执行；它的 PlayMaker 状态机也先停着，之后每帧拿几毫秒逐个初始化（物品拾取那种为每种物品提前生成提示 UI 的动作在用到时才生成）。走过门线时不走空洞骑士的切场景流程，只是把隔壁设成当前场景（活动场景、场景管理器、地图、存档里的场景名都跟着换），不相邻的场景卸掉，新的邻居在后台接着载入。门、长椅、死亡这类原版切换会先卸掉所有邻居，再按原版流程进新场景。被挪动过的场景里，状态机读写坐标（取位置、设位置、移动到某点、在某点生成物体）时会换算成该场景自己的坐标，所以电梯、巡逻范围这些写死数字的逻辑照常工作。

## 环境要求

- 空洞骑士 Steam 版 1.5.12620（当前正式版，Unity 6）
- 泰拉瑞亚（1.4），默认在同一个 Steam 库里自动查找，找不到时在 `BepInEx/config/com.haoawake.terraknight.cfg` 里填 `TerrariaDir`
- BepInEx 5.4.23.x（win x64）

## 配置

`BepInEx/config/com.haoawake.terraknight.cfg`：

| 配置项 | 说明 |
|---|---|
| `Paths.TerrariaDir` | 泰拉瑞亚目录，留空自动查找 |
| `Gameplay.TerrariaMovement` | 泰拉瑞亚移动手感，关掉保留空洞骑士手感 |
| `Gameplay.CenteredCameraExperimental` | 实验功能，默认关：泰拉瑞亚式镜头，人物每一帧都在画面正中间，不管房间原版的镜头锁定区和场景边缘（和无缝地图一起用才合适）。关着时是空洞骑士原版的镜头 |
| `Gameplay.SeamlessWorldExperimental` | 实验功能，默认关：相连的场景（左右、上下）拼成连续地图、提前载入。关着时是原版的过门读取 |
| `Gameplay.TerrariaMap` | 泰拉瑞亚式世界地图（照碰撞体一格一格画、走到哪里揭开到哪里）；关掉则用空洞骑士地图块拼的旧地图 |
| `Gameplay.MapStyle` | 地图显示方式：0 不显示，1 右上角小地图，2 覆盖在画面上（Tab 切换时自动保存） |
| `Gameplay.HollowKnightDarkness` | 保留空洞骑士的黑暗：没有光蝇灯笼时，黑暗区域（呼啸悬崖边缘、深巢、水晶山峰的矿道等）会把视野缩成人物周围一小圈，慢慢变暗。默认关：不缩视野（开着泰拉瑞亚光照时这些地方仍按泰拉瑞亚的方式是暗的） |
| `Gameplay.TerrariaLighting` | 泰拉瑞亚式光照（默认开）：按格子算光，火把、头灯、子弹和法术、晶塔的光一格一格柔和地照亮四周的场景，穿过方块暗得很快；挖开的隧道、放下的方块和黑暗区域里光照不到的地方是暗的，原版房间的空地和地形照原版的样子。关掉则用旧的光晕 |
| `Gameplay.EnemyHealthBarsAlways` | 敌人的血条一直显示；默认关，和泰拉瑞亚一样掉了血才显示（“泰拉瑞亚设置”里也能切换） |
| `Gameplay.AutoReuseAllItems` | 泰拉瑞亚设置里的“自动开火”：所有武器按住鼠标就一直挥舞、射击；默认关（“泰拉瑞亚设置”里也能切换） |
| `Multiplayer.PlayerName` | 多人模式里的名字，留空用 Steam 昵称 |
| `Multiplayer.Look` | 多人模式里的外观配色，0 是泰拉瑞亚默认人物的颜色，1-7 其他配色 |
| `Multiplayer.LastAddress` / `Multiplayer.Port` / `Multiplayer.MaxPlayers` | 上次加入的地址、端口（默认 7777）、开服时的最多人数（默认 8，最多 16） |
| `Multiplayer.SyncEnemies` | 多人模式里同一场景共用一批敌人（默认开）；关掉则各打各的 |
| `Keys.*` | 泰拉瑞亚按键（Unity Input System 的键名，如 `W`、`Space`、`LeftShift`、`Digit1`、`F1`），游戏里在“泰拉瑞亚设置”里改更方便 |
| `Gameplay.EnemyMultiplier` | 普通敌人的数量倍数，默认 2（翻倍），1 为原版数量 |
| `Gameplay.BossDamage` | 首领的伤害是同区域普通敌人的几倍，默认 2 |
| `Gameplay.EliteDamage` | 精英的伤害是同区域普通敌人的几倍，默认 1.5 |
| `Gameplay.SkipOpeningCutscenes` | 新游戏跳过开场的序章诗和开场动画，加载好直接在国王山道从传送门里走出来，默认开 |
| `Gameplay.EnemyRespawnScale` | 普通敌人重新刷出的等待时间倍数：按强弱分档（30 / 45 / 70 / 100 秒，精英 4 分钟）乘以它，默认 1，0 为不刷新（旧设置 `EnemyRespawnSeconds` 填 0 也是不刷新） |
| `Video.TargetFrameRate` | 游玩时锁定的帧率，默认 144（会关掉垂直同步），0 用游戏自己的设置 |
| `Dev.InfiniteItemsAllSaves` | 开发用：所有存档都像创造模式一样物品用不完、制作栏全部解锁、不要吉欧（自动测试时也开着）。较早版本的 `Dev.InfiniteItems` 设置没有作用 |
| `Dev.AutoTestSlot` | 开发用：1-50 时启动后自动进入这个存档位跑测试并截图，0 关闭 |
| `Dev.AutoTestSuite` | 开发用：`all` 跑全部测试，`seamless` 只测无缝地图，`profile` 无缝地图加后台载入的脚本初始化计时，`move` 移动手感，`items` 武器 / 炸弹 / 方块 / 盔甲 / 药水，`ui` 地图 / 背包界面和下砸地板，`lift` 呼啸悬崖的鹿角站电梯，`fixes` 浮空地形的贴图 / 挖掉的荆棘 / 席奥小屋，`features` 背包操作和制作栏 / 剑气 / 鼠标悬停和血条 / 飞毯 / 抓钩 / 晶塔 / 丢东西捡东西 / 击退距离，`platform` 智能光标铺平台和楼梯、在楼梯上走、穿过平台，`ammo` 每种箭和子弹打一发，`weapons` 新加的 17 把武器，`accessories` 新加的 23 件饰品（跳跃高度、多段跳、翅膀、跑速、滑墙、伤害加成、受伤触发），`accvisual` 只拍饰品穿在身上的样子，`swords` 困难模式近战（剑、长枪、回旋镖：伤害、生成的弹幕和命中数、枪尖距离），`ranged` 困难模式枪弓，`magic` 困难模式魔法（耗魔、减益），`visual` 越过门线时每帧的画面和镜头，`creative` 创造模式按钮、选存档位、选难度、存档标签和普通新游戏问难度，`book` 怪物图鉴（发现、收集、地区分栏、创造模式全解锁），`torch` 开局物品、火把光照、手持火把、Shift 智能切换，`door` 国王山道大门和开头木板（贴近、上下、开关 mod 的处理对照）和贴墙挖岩壁，`pylon` 晶塔传送到达的传送门和各地区配色，`prompts` 能力提示拦截和骨钉大师/骨钉匠的对话跳转，`balance` 平衡性数值表（各阶段×各难度的击杀耗时和挨几下会死）和开局实测，`fsmdump` 导出能力拾取、骨钉大师、骨钉匠的状态机，`onewall` 呼啸悬崖入口的石墙（贴住和退一步各打两下）、提克提克不吃击退、坠落之星帧数、背包重开时图鉴收起、地图（无缝走进呼啸悬崖后是否记作去过、头像是否居中、鹿角虫巢里的头像），`wall` 开局往左的岩壁，`route` 沿呼啸悬崖走一圈看地图头像和光照（来回越线、原版切换、进出暗区后同一位置的暗度和环境光），`blockers` 把每个场景挨个载入，列出所有挡怪墙和各场景自己规定的地图范围，`blockfix` 呼啸悬崖暗道口：飞虫在挡怪墙开着和关掉时能不能飞进来，`layout` 把每个场景挨个载入，记下门的位置和两边的地面（世界地图的拼法由 scratchpad 里的 maplayout/greedy.py 算出），`worldmap` 世界地图：走过山道、德特茅斯和呼啸悬崖后揭开了多少、记下了哪些物件、长椅门路灯地面指着叫什么、远近截图、地图存档读写，`showcase` 创造模式展示装备（四套配装、背包武器）和手拿纯弹药不能扔，`welldump` 导出遗忘十字路井底和德特茅斯换场景的状态机和门，`well` 德特茅斯的井：掉下去、从井底直接飞上去、按上从井底的门回去（每步的状态和截图，接缝两侧的井壁贴图），`creative2` 创造模式的整张地图、全部晶塔（传送到远处的晶塔）和图鉴生成按钮，`holdpose` 十几把武器举在手上的样子和弹幕第一帧画在哪，`pylonall` 创造模式挨个传送到全部 40 座晶塔（到没到、能不能动、有没有往下掉、暂停有没有锁住、黑屏、用时、坐着出发），`bags` 创造模式的四个背包（展示背包、切换、互不共享、存档读回、旧存档补背包、普通存档一个背包），`tour1`–`tour6` 世界地图上的全部场景分六段挨个进（黑屏、卡在地形里、左右走不动、掉出场景、报错），`boss1`、`boss2` 野外的首领和精英挨个叫醒打死（死没死、图鉴记没记、死后能不能动、报错），`stations` 普通存档里用木材空手做工作台、放下后做木甲/熔炉/砧、放熔炉和砧、敲掉工作台、存档读回，以及各难度的掉率和数量，`l10n` 强制成英语/日语/俄语看物品、Buff、界面文字，截图背包，列出还没翻译的行，`promo`、`promo2`、`promo3`、`promoA`–`promoF` 录宣传片素材（逐帧录到 `dev/rec/<片段>/`，见下面的“宣传片”），`pylonfade` 从泪水之城传送到隔壁已载入的场景看会不会黑屏。任何一组后面加 `_zh`（比如 `promoA_zh`）就让游戏这一次用简体中文跑（只在内存里切换，存档里的语言设置不动），录下的片段名前面加 `zh_` |

## 开发

```
# 第一次：复制路径配置并改成你的空洞骑士目录
copy LocalPaths.props.example LocalPaths.props

# 编译，dll 会自动复制到 <空洞骑士>/BepInEx/plugins/TerraKnight/
dotnet build src/TerraKnight
```

- `tools/XnbDump`：把泰拉瑞亚的 .xnb 贴图解成 PNG、批量验证贴图和音效解码、渲染物块拼接测试图，不需要启动游戏。
- 自动测试（`Dev.AutoTestSlot`）：用指定的存档位开新档或读档，跳过开场动画，在国王山道里测：
  - 饰品手感（靴子加速、盾冲刺和撞击、云朵瓶二段跳，按泰拉瑞亚的像素/帧记录速度）、攀爬爪滑墙；
  - 智能光标的挖掘顺序、天顶剑的飞剑、抓钩钩住和拉人；
  - 镐子敲吉欧石、挖坑、放方块、站立和下落、挥武器砍敌人和道具，挖掉手放的地形碰撞；
  - 走过右门进德特茅斯（切换那一帧多长、有没有走原版切换、挖进去的格子还在）、走回来并继续往里走、从井掉进遗忘十字路（邻居场景里的敌人在动）、从十字路往左越线；
  - 挨一下打（击退、无敌、闪烁、不顿帧），然后死一次（复活后站着不动不会来回切换、影子留在死的那个场景自己的坐标里）；
  - 从德特茅斯走回国王山道，被没破的大门挡住，砍开它。

  另外几组单独的测试（`Dev.AutoTestSuite`）：`v10` 测 1.0 的修正（德特茅斯上空的空气墙和左门、缩壳的巴德尔长者吃不吃箭和召唤物、白色宫殿和苍绿之径入口的小地图、门后房间只在里面时画出、首领的泰拉瑞亚数值），`layoutmissing` 只调查地图上还没有位置的场景（不动世界图集），`bossgates` 列出每个首领场地里决定这场战斗打不打的存档记录（`arena` 挑战按钮的依据），`ammoslots` 测弹药栏（找弹药的顺序、捡起时进哪格、只放得进弹药、射箭先用弹药栏），`arena` 测创造模式图鉴里的首领挑战（进场、首领在不在、离开后记录放回原样、梦境和神居打完回到原处），`fixes` 挖空浮空平台看贴图有没有一起消失、在挖空的荆棘上碰一下看会不会受伤、进席奥小屋看有没有把苍绿之径叠进来；`features` 用制作栏和背包的各种点法、对着敌人挥每把剑（剑气、闪光、扣血）、鼠标指着敌人看名字和血量、铺飞毯、在德特茅斯坐椅子解锁晶塔再传送回来；`visual` 越过几处左右和上下的门线，逐帧记录画面亮度变化和镜头偏移，再站在接缝上看会不会来回切换；`tuning` 晶塔（照游戏的顺序：先坐下、过一会儿才设复活点）、敌人强度和首领精英的霸体（和原版受击对照）、刷新和尸体、雷达；`loadout` 切换四套配装、共享饰品和存档迁移；`summon` 召唤杖、仆从、鞭子和标记；`progression` 物品阶段与来源、配方、吉欧零头、敌人翻倍和重生、击杀计入图鉴和掉落、德特茅斯的 NPC 对话、商店买卖和回购，并给城镇、对话框、商店和图鉴截图；`platform`、`ammo`、`weapons`、`accessories` 分别把平台楼梯、全部弹药、新武器和新饰品的数值和泰拉瑞亚原版对照记进日志（比如长枪刺多远、每种额外跳升多高、翅膀爬多高、滑墙多快）。`bossrun` 按正常玩法把世界里的 20 个首领和精英打一遍：从首领房间自己的门进场、走近或走进触发区唤醒、在挑战提示前按上（螳螂领主），然后只用 mod 自己的攻击打（无敌帧照算，打在盔甲上也照打），直到游戏自己记下击杀；记录用时、掉落、尸体上有没有残留血条、打完能不能操作、期间的报错（`bossrun_A+B` 只打其中几个）；`water` 在吸虫之母的水池里落水再跳出来，开打前和它死后各一次。
  
  截图保存在 `BepInEx/TerraKnight/dev/`，日志在 `BepInEx/LogOutput.log`；Unity 自己的报错在游戏存档目录的 `Player.log`（BepInEx 默认不写进 LogOutput.log）。
- 宣传片（`promo/`）：
  - 素材由自动测试录。第一版（30 帧）：`promo` 四个职业各打一个大师模式首领、德特茅斯的井、地图和晶塔、放工作站；`promo2`、`promo3` 灵魂战士、往下挖、苦痛之路、重力球。第二版（50 帧，每帧正好一步物理，动作更顺）：`promoA` 从存档界面开始（点“创造模式”、选存档位、把四个难度挨个指一遍、选大师）、国王山道的传送门开局，然后德特茅斯的 NPC、跟商人对话和买东西、图鉴（打开、指几个、选一个、点“生成”，再把同一条目从普通换到大师看数值和掉率变化）、制作栏、四套配装切换；`promoB` 九个首领（翅膀悬停、保持距离、瞄准平滑过渡，每个职业换没用过的武器）、十字路的掉落、十六把武器轮流用；`promoC` 苦痛之路整间（先按危险物的真实形状做广度优先搜索规划路线，再沿平滑曲线匀速飞完）、月钩、往下挖、重力球、地图点晶塔传送；`promoD` 只录武器；`promoE` 只录地图晶塔；`promoF` 从泪水之城打开地图点晶塔（图标在画面里，传送到达也录下来）。界面操作用测试专用的指针（`TerraCursor.DevDrives`）：光标沿曲线滑到按钮上、停一下再点，悬停效果和真鼠标一样。帧在 `BepInEx/TerraKnight/dev/rec/<片段>/`，压成的片段在 `promo/clips/`（`encode_clips.py`），缩略图在 `promo/sheets/`（`timesheet.py` 出带时间的）。
  - `make_music.py` 合成配乐 `music.wav`（原创的 140 BPM 电子乐，不用任何采样）和节拍表 `beats.json`；`edl.py` 是剪辑表（每个镜头从哪段素材的第几秒开始、多快、怎么裁、怎么转场，字幕，都按拍子算；同一段素材的同一段时间不会用两次，脚本里有检查；第一版是 `edl_v1.py`）；`make_promo.py` 照剪辑表逐帧渲染成 `TerraKnight_promo.mp4`（`--range 30 40` 只渲一段看效果，`--endcard` 只渲片尾）；`make_jianying.py` 用 jianying-editor 技能把同一份剪辑表做成剪映草稿“泰拉圣巢宣传片”，可以在剪映里接着改。中文版：用 `promoA_zh`、`promoB_zh`、`promoC_zh`、`promoF_zh` 录 `zh_` 片段，再 `PROMO_LANG=zh python make_promo.py` 出 `TerraKnight_promo_zh.mp4`（同一份剪辑，`edl.py` 的 `ZH_SHOT` 里只改了重录后时间变了的镜头），`PROMO_LANG=zh python make_jianying.py` 出剪映草稿“泰拉圣巢宣传片（中文版）”。
