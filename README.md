**中文** | [English](README.en.md)

## 下载和安装

只支持 Windows（64 位）。整个过程大约五分钟。

### 1. 准备

- **空洞骑士** Steam 版，当前正式版 1.5.12620。
- **泰拉瑞亚** Steam 版 1.4.x，**必须装在这台电脑上**：mod 的贴图、音效、物品名和文字都直接读本机泰拉瑞亚的文件，不随 mod 打包，所以不用担心版权素材的问题，但没装泰拉瑞亚就玩不了。两款游戏装在同一个 Steam 库里时会自动找到。
- 建议用新存档玩 mod，并先备份原版进度：存档在 `%USERPROFILE%\AppData\LocalLow\Team Cherry\Hollow Knight`。mod 玩过的存档里的进度是按 mod 的规则来的（比如没有冲刺和法术），mod 自己的数据另存在同目录的 `TerraKnight_slot*.json`。

### 2. 装 BepInEx（mod 加载器）

1. 打开 [BepInEx 的发布页](https://github.com/BepInEx/BepInEx/releases)，下载 **BepInEx 5.4.23.x** 的 `BepInEx_win_x64_5.4.23.x.zip`（不要下 6.x 或 x86 版）。
2. 在 Steam 里右键空洞骑士 → 管理 → 浏览本地文件，打开游戏目录（里面有 `hollow_knight.exe`）。
3. 把压缩包里的东西全部解压到这个目录，解压后目录里会多出 `BepInEx` 文件夹、`winhttp.dll` 和 `doorstop_config.ini`。
4. 从 Steam 启动一次空洞骑士，等到主菜单再退出。BepInEx 会在 `BepInEx` 里建好 `plugins`、`config` 等文件夹。

### 3. 装泰拉圣巢

1. 打开本项目的 [Releases](https://github.com/haoawake/TerraKnight/releases)，下载最新的 `TerraKnight-vX.Y.Z.zip`。
2. 把压缩包里的东西全部解压到**同一个游戏目录**。解压后应该是这样：
   ```
   Hollow Knight/
   ├─ hollow_knight.exe
   ├─ 泰拉圣巢.bat                 ← 启动器
   ├─ terraknight-launch.ps1
   └─ BepInEx/
      └─ plugins/
         └─ TerraKnight/
            └─ TerraKnight.dll
   ```
3. 双击 `泰拉圣巢.bat` 开始游戏。第一次进主菜单时，中文的大标题会变成“泰拉圣巢”（英文界面保持原样）；新建存档时会先让你选难度（普通、困难、专家、大师），存档界面右下角的“创造模式”按钮可以开一个物品用不完的创造存档。

从 Steam 直接启动就是原版空洞骑士：启动器只在它启动游戏的那一刻打开 BepInEx，游戏起来后马上关回去（见下面的“启动”）。刚装好 BepInEx 时开关是开着的，所以在第一次用启动器之前，从 Steam 启动也会带着 mod。

### 4. 可能遇到的问题

- **进游戏还是小骑士 / 没有任何变化**：确认是用 `泰拉圣巢.bat` 启动的；再看 `BepInEx\LogOutput.log`，里面应该有 `TerraKnight` 的加载记录。没有这个文件说明 BepInEx 没装对（多半是解压错了目录，或者下成了 x86 / 6.x 版）。
- **日志第二行是 `Running under Unity v2020...`、没有 `com.haoawake.terraknight.cfg`、日志里有 `Could not find method for type HeroController and name SendHeroInPosition`**：空洞骑士是 1.5.78 旧版本（老的 Modding API 模组要的那个测试版分支）。泰拉圣巢只支持 1.5.12620 当前正式版（Unity 6000）。在 Steam 库里右键空洞骑士 → 属性 → 测试版，选“无”，等它更新完再用 `泰拉圣巢.bat` 启动；第一次正常加载后 cfg 才会生成。新版 mod 遇到旧版游戏时在日志里写明这一点，并且不加载。
- **启动时报错 `MissingMethodException: Method not found: Mono.Cecil.MethodDefinition MonoMod.Utils.DynamicMethodDefinition.get_Definition()`（出现在 `BepInEx.Preloader` / `ConsoleSetOutFix`）**：游戏里装着空洞骑士的 Modding API（Scarab、Lumafly 等模组管理器安装的），它放进 `hollow_knight_Data\Managed` 的 MonoMod、Mono.Cecil 先于 BepInEx 自带的版本被加载，BepInEx 因此启动失败。在模组管理器里关闭 Modding API，或者在 Steam 里对空洞骑士“验证游戏文件的完整性”后删掉 `hollow_knight_Data\Managed` 里的 `MonoMod*.dll`、`Mono.Cecil*.dll`、`MMHOOK_*.dll`，再用 `泰拉圣巢.bat` 启动。启动器检测到这些文件时会弹窗说明，不会带着冲突启动。
- **日志里说找不到泰拉瑞亚**：在 `BepInEx\config\com.haoawake.terraknight.cfg` 里把 `TerrariaDir` 填成泰拉瑞亚的目录（里面有 `Terraria.exe` 和 `Content` 文件夹），比如 `D:\SteamLibrary\steamapps\common\Terraria`。
- **双击 bat 一闪而过、游戏没起来**：确认 Steam 开着；游戏已经在运行时启动器不会重复启动。
- **语言**：mod 跟着空洞骑士自己的语言设置走（游戏的选项 → 游戏 → 语言），泰拉瑞亚的物品名和文字会一起换成对应语言。
- **更新**：下载新版压缩包，覆盖解压到游戏目录即可；存档保留。
- **卸载**：见文末的“卸载”。

## 功能一览

- **标题画面**：中文（简体、繁体）的主菜单大标题从“空洞骑士”换成“泰拉圣巢”（繁体“泰拉聖巢”），花纹、位置和大小都照原版，虚空之心主题的副标题也保留。
- **泰拉瑞亚人物**：默认的泰拉瑞亚角色替换小骑士，有站立、走路、跳跃、挥动的动画。
- **开局**：新游戏点击后跳过序章诗和开场动画（加载约 5 秒的黑屏后直接进入），人物直接出现在国王山道底部的地面上：一扇撒旦军团的神秘传送门旋开，紫色光尘卷进门里，人物从门中淡入走出来，门随后收拢并炸开一圈闪光（用的是泰拉瑞亚原版的传送门贴图和音效）。新存档开局有铜短剑、铜镐、木弓和 100 支木箭（放在弹药栏）、10 支火把，抓钩装在“其他装备”页的钩爪格里，并戴着攀爬爪和云朵瓶。
- **难度和创造模式**：每次新建存档都会先选难度（普通、困难、专家、大师，图标和颜色用泰拉瑞亚创建世界的）。大师是 mod 原本的数值，普通的敌人血量是大师的四分之一，困难一半，专家四分之三（首领按泰拉瑞亚自己的普通 / 专家 / 大师生命，困难取普通和专家的中间）；敌人伤害也按同样比例：先按大师算出扣掉你防御后的伤害，再乘这个比例，所以不管护甲多好，普通难度挨的打始终是大师的四分之一。存档界面右下角有“创造模式”按钮：选一个存档位（已有存档要再确认一次覆盖），再选难度，就在那里开一个创造模式存档。创造模式下物品用不完，获得一次就是无数个，制作栏随时随地免费做出任何物品，商店不要钱，钱一直是 99,999,999（花了马上补满），怪物图鉴全部解锁。创造模式存档还会：整张世界地图全部显示（379 个场景，图集由 `layout` 测试从你自己的游戏文件生成，存在 `BepInEx/TerraKnight/worldatlas.bin`）；全部 40 张长椅旁的晶塔都解锁，没去过的地方也能直接传送，到了以后晶塔会挪到那张长椅旁边；图鉴里每个敌人右上角有“生成”按钮：普通敌人和精英点一下就生成在人物面朝方向 10 格外（不在当前场景的敌人会临时从它所在的场景借一个过来）；**首领点一下会把你直接送到它自己的场地，从头打一遍**：开场动画、对话、剧情都照原版触发，打过的也一样（进场前把它“已击败”的记录临时改回没打过，战士之梦的亡灵临时给上梦之钉，格林临时满足剧团的条件；离开场地后全部改回原样，这次打赢了就记作打赢）。梦境首领和神居首领打完会回到你点按钮时站的地方。创造模式存档的四套配装各有自己的背包，切换配装（F1–F4 或装备栏旁的按钮）时整个背包跟着盔甲饰品一起换，四个背包互不共享；普通存档还是四套配装共用一个背包。新开的创造模式存档自带一套录视频用的展示装备：四套配装分别穿上日耀、星旋、星云、星尘套装和最适合各职业的饰品；每个职业的背包第一格是该职业最好的武器（天顶剑、太空海豚机枪、终极棱镜、泰拉棱镜），第二格是该职业的月亮镐，后面是该职业的其他展示武器和月钩，远程背包的弹药放在弹药栏里；生命水晶、生命果、魔力水晶和各种永久增益都吃满。较早版本创建的创造存档读进来时，已有的背包留给当前配装，另外三个配装各补上自己职业的展示背包。创造模式还把三张收费长椅（泪水之城、王后花园、远古盆地）当作已付费。普通存档只能一个一个捡东西，也只能用背包里已有的材料合成。存档格上会显示“创造模式”和难度。

- **泰拉瑞亚玩法**：
  - 空洞骑士的骨钉、冲刺、法术、聚集、二段跳、蹬墙全部去掉。移动能力以后改由泰拉瑞亚饰品获得；梦之钉变成背包里的一件物品（见下面的“梦之钉”）。
  - 生命值 100、魔力 20，右上角是泰拉瑞亚的红心和魔力星。被打时按面具换算成泰拉瑞亚伤害（越深的区域每个面具越疼），会自然回血，坐椅子回满。
  - 移动手感是泰拉瑞亚的：跑速、加速度、跳跃高度、下落速度都按原版数值换算，有摔落伤害（从侧门、底门进房间时原版自带的那段落差不算；首领房间不能挖不能搭，里面也不算）。
- **挖和放**：场景地形换成了 0.5 单位的格子，每格都能挖、能放。挖开的地方会露出泰拉瑞亚的背景墙，颜色跟着区域走：国王山道和十字路是蓝灰洞穴墙，苍绿之径丛林墙，王后花园花墙，雾之峡谷珍珠石墙，真菌荒地橙色砂岩墙，泪水之城蓝色地牢砖，皇家水道绿色地牢砖，水晶山峰紫晶墙，安息之地紫灰洞穴墙，深巢蜘蛛墙，王国边缘大理石墙，蜂巢蜂巢墙，远古盆地花岗岩墙，深渊和黑卵神殿黑曜石墙，白色宫殿珍珠石砖，神居金砖，梦境神圣砂岩墙，格林剧团猩红石墙，愚人斗兽场丛林蜥蜴砖，德特茅斯、呼啸悬崖等其他地方是石墙；挖的时候掉泰拉瑞亚的碎屑；地形边缘伸出去的草皮、石沿在下面被挖空后也会一起去掉。

- **阶段**（详见 [阶段对照.md](阶段对照.md)，里面有每个阶段对应泰拉瑞亚的哪段进度、每个空洞骑士首领对应哪个泰拉瑞亚首领）：空洞骑士的全流程**按小骑士获得能力的路线**对应泰拉瑞亚的进度分成六个阶段。**解锁**（德特茅斯搬来新 NPC、商店上新、工作站开放新配方）看拿到了几样关键能力：蛾翼披风（大黄蜂给的，相当于打完克苏鲁之眼拿到克苏鲁护盾）→ 1，螳螂爪 → 2，水晶之心 → 3，帝王之翼（残破容器之后，相当于打完血肉墙进困难模式）→ 4，暗影披风 → 5；已经搬来的 NPC 不会走，向导会提示下一样该去找什么。**敌人的强度和掉落**按它所在的区域，区域也按这条路线分：0 国王山道、德特茅斯、遗忘十字路、苍绿之径（到大黄蜂为止）；1 真菌荒地和螳螂村、雾之峡谷、呼啸悬崖（拿到蛾翼披风后，克苏鲁之眼之后）；2 泪水之城、皇家水道、水晶山峰、安息之地（拿到螳螂爪后：世界吞噬怪 / 克苏鲁之脑、地牢）；3 深巢、野兽巢穴、远古盆地、王后花园（拿到水晶之心后：蜂后、地狱、血肉墙）；4 王国边缘和里面的蜂巢、愚人斗兽场、深渊（帝王之翼之后：困难模式）；5 白色宫殿、神居、梦境、格林剧团、最终战（直到月亮领主）。区域越深敌人越强，掉的东西也越好。所有物品（武器、饰品、盔甲、弹药、材料）都按原版最早能拿到的时间（泰拉瑞亚的来源和稀有度）和在圣巢里的来源分到了阶段里，比如捣蛋猫和火绒狐分别在阶段 2、3 才掉，生命果要到王国边缘，世纪之花之后的武器只在阶段 5 出现。
- **物品怎么来**：照泰拉瑞亚原版的来源分三种。
  - 原版由城镇 NPC 卖的，在德特茅斯找对应的 NPC 买（见下）。
  - 原版合成的，用左下角的制作栏按原版配方合成：比如 6 个铜锭做铜阔剑，魔光剑 + 村正 + 草剑 + 火山合永夜刃，赫尔墨斯靴 + 火箭靴做幽灵靴，再加疾风脚镯和鞋带束头做闪电靴，一路合到泰拉刃和天顶剑。新加了原版配方要用的 65 种材料（各种锭和锡/铅/银/钨锭、乌木/红木/珍珠木/暗影木/棕榈木/针叶木/灰烬木、仙人掌、晶状体、羽毛、毒刺、丛林孢子、骨头、暗影鳞片、各种魂、碎片等）和 14 件中间装备（镣铐、黑曜石骷髅头、泰坦手套、大自然的恩赐、两种瓶子气球、真永夜刃、真断钢剑、种子弯刀、无头骑士剑、波涌之刃、彩虹猫之刃、狂星之怒等）。锭不用挖矿熔炼，直接从怪物身上掉。
  - 原版靠宝箱、怪物或 Boss 掉的，变成某种空洞骑士怪物的固定掉落。
  - 写着“徒手”的配方在哪都能做，不用靠近长椅。
  - **箱子**（R7）：商人卖宝箱，在地面上放下（两格宽的平地，在够得着的范围内），右键打开，背包下面出现 40 格：点击拿放，Shift 点击在背包和箱子之间整堆转移，右侧有“全部拿取 / 全部存放 / 快速堆叠 / 补货（用箱子里的东西把背包里同种不满的堆补满）/ 排序物品”。不开箱子时，背包右下（弹药栏下面）有泰拉瑞亚的两个按钮：“快速堆叠至附近的箱子”（600 像素内、箱子里已经有同种东西的，把背包里非收藏、非快捷栏的那些放进去）和“排序物品”（快捷栏和收藏的不动，其余按武器、工具、盔甲、饰品、药水、方块、材料分类，稀有的、贵的在前，同种的合并）。走远或关掉背包会自动关上，盖子有开合动画。空箱子可以用镐子挖回来（有东西时挖不动），箱子和里面的东西跟着存档保存在它所在的场景。
- **制作栏**：和泰拉瑞亚一样只列出材料够的配方。材料算背包里的，加上人物 8 格内箱子里的：合成时先用背包里的，不够再从箱子里取。选中配方时旁边显示需要的材料和数量（不够的标红），鼠标放在材料上显示背包和附近箱子里各有多少，点一下合成到光标上。工作站按阶段解锁：砧、工作台一开始就有，工匠作坊从阶段 1、秘银砧和水晶球从阶段 4、远古操纵机从阶段 5 才算有，都在长椅旁或德特茅斯使用。方块、木材、火把、平台、绳这些基础东西照旧花吉欧直接做。四套配装的制作栏仍按职业分。
- **货币**：买卖都用吉欧。**吉欧是背包里的实体物品**（图标是右上角吉欧计数器的那枚硬币），一叠最多 2,147,483,647 个，可以扔在地上、放进箱子、存进**猪猪存钱罐**（商人卖，100 吉欧左右；放在地上右键打开 40 格私人仓库，每个存钱罐里都是同一份）。原版的吉欧照常掉落和拾取，捡到就变成背包里的吉欧；左上角吉欧计数器显示的是背包加存钱罐的总数：鹿角站、收费长椅、斯莱的商店、德特茅斯的商店都按总数算，先扣背包里的，不够再扣存钱罐里的。死后的亡魂只带走背包里的吉欧，存钱罐里的不会丢。较早版本的存档第一次读档时，存档里的吉欧数换成等量的吉欧物品。**价格**：1 银币以内的东西照原版价值（1 吉欧 = 1 银币，不足 1 吉欧的零头会记下来，比如 7 铜的火枪子弹是 0.07 吉欧），更贵的按价值的 0.8 次方增长，免得泰拉瑞亚的金币、铂金币价位远超圣巢的吉欧：1 金币的东西约 40 吉欧，10 金币约 250，1 铂金约 1600。卖东西得买价的五分之一；原版没有价值的东西（土块、石块、木材这类），以及只用这些东西就能做出来的东西（工作台、木头盔甲……），都卖不了钱。吉欧不能卖。能堆叠的物品一格最多 9999 个。
- **矿石和金属盔甲**：怪物掉矿石（铜、锡、铁、铅、银、钨、金、铂金、魔矿、陨石、狱石、钴、钯金、秘银、山铜、精金、钛金、叶绿），数量按几矿一锭折算。矿石在熔炉炼成锭（铜锡铁铅魔矿陨石钴钯金 3 个一锭，银钨金铂金秘银山铜 4 个，狱石 3 个加 1 个黑曜石在地狱熔炉，精金钛金 4 个、叶绿 5 个在精金熔炉；长椅旁按阶段也能炼）。新加锡、铅、银、钨、铂金五套盔甲（照原版的防御和配方，在砧上做），套装奖励锡 +2、铅银钨 +3、铂金 +4 防御。
- **首领房间**：首领的房间（每个首领、精英所在的房间，苍绿之径的大黄蜂、格林剧团的帐篷、愚人斗兽场；以及任何有首领或精英活着的房间，比如召出来的战士之梦）里不能挖、不能放方块和平台、不能放工作站和箱子、炸弹炸不动地形、冰魔杖冻不出冰块，原汁原味地打。试的时候光标上会提示“首领房间里不能改动地形”。
- **无敌帧**：怪物挨了一下之后有一小段无敌帧，期间别的攻击直接穿过去：首领 10 帧（1/6 秒）、精英 8 帧、普通怪 4 帧，不管是武器、弹幕、召唤物还是哨兵。所以首领每秒最多吃 6 下，一大群召唤物或高射速的枪按这个节奏打首领，单发伤害高的武器基本不受影响。中毒、着火这类持续伤害不算挨打，不受限制。
- **其他装备**：装备栏上方有泰拉瑞亚的切页图标，切到“其他装备”页是宠物、照明宠物、矿车、坐骑、钩爪五格（钩爪格可用，坐骑和宠物格留待以后的版本）。按 E 用钩爪格里的钩子，格子空着时用背包里找到的第一个（和原版一样）；背包里右键钩爪直接装上。
- **德特茅斯的城镇 NPC**：泰拉瑞亚自己的 NPC 都住在德特茅斯的大街上，到了对应阶段就搬来（会显示“X已到达！”），在长椅附近闲逛，有传送晶塔所以随时能回来。在够得着的地方右键 NPC 和它说话（原版的对话框和台词），点“商店”打开原版的商店面板：左键或右键买到光标上，按住越买越快，Shift 一次买 10 个；Ctrl+左键背包里的东西卖掉，或把光标上的东西放到商店空格里卖掉，卖掉的东西会留在商店里，关掉商店前可以按卖价买回来。德特茅斯街道前面那排近景剪影（岩石、草丛）原本是给空洞骑士抬高的镜头看的，处在画面下沿；镜头以人物为中心时它们会被抬到街道上方挡住 NPC，所以在城镇里把它们藏起来了。

- **工作站和合成**：和泰拉瑞亚一样，工作台、熔炉、铁砧/铅砧、秘银砧/山铜砧、锯木机、织布机、工匠作坊（哥布林工匠卖）都是能放在地上的家具，玻璃瓶放在地上就是炼药台。站在它们附近（左右 5 格、上下 4 格）就能做对应的配方；敌人掉的木材空手就能做工作台、木平台和火把（凝胶+木材），放下工作台后能做木头盔/木胸甲/木护胫（一套 +1 防御）、木剑、木锤、木弓、木箭、熔炉和砧，在砧上做链条，链条加铁锭做锯木机，锯木机旁做织布机。用镐子敲工作站会掉回物品，存档会记住每个场景里放了什么。靠近长椅或在德特茅斯时，也按阶段解锁所有工作站。工作台、铁砧/铅砧、秘银砧/山铜砧和工匠作坊顶上能站人，按住下能穿下去，上面还能放别的家具（比如把铁砧或玻璃瓶放在工作台上）；工作站脚下的地面被挖掉时，它和它上面的家具一起掉回物品。箱子脚下的那格挖不掉，方块也放不进工作站和箱子占着的格子。
- **怪物掉落和图鉴**：像冒险岛一样，每种怪物有自己固定的掉落表（除了吉欧，还有一定几率掉本阶段的材料、武器、饰品或盔甲），比如游荡躯壳掉铜锭铁锭、偶尔掉镣铐，蜂巢的怪掉蜂蜡和毒刺，深巢的蜘蛛掉蛛网和蜘蛛牙。Boss 只打一次，所以它们的标志性物品必掉，掉的就是它顶替的那个泰拉瑞亚首领（或那段进度）的东西：假骑士（史莱姆王）掉史莱姆法杖，大黄蜂（克苏鲁之眼）掉魔矿锭和克苏鲁护盾，守望者骑士（血肉墙）掉四种徽章和鞭炮，蜂巢骑士（蜂后）掉养蜂人和蜂窝，空洞骑士（石巨人）掉锯刃镐，梦魇之王（猪龙鱼公爵）掉海啸和利刃台风，失落近亲（光之女皇）掉万花筒和泰拉棱镜。**月亮领主的装备按职业分给了神居的四位神**：伟大骨钉贤者斯莱掉近战的（彩虹猫之刃、狂星之怒、泰拉悠悠球），骨钉大师奥罗和马托掉远程的（太空海豚机枪、喜庆弹射器Mk2、幻影弓），绘画大师席奥掉魔法的（终极棱镜、月耀……），纯粹容器掉召唤的（七彩水晶法杖、月亮传送门法杖……），每位神还像四柱一样掉自己职业的夜明碎片；辐光掉月亮领主自己的夜明锭和重力球。每个首领对应谁、掉什么见 [阶段对照.md](阶段对照.md)。背包里点“怪物图鉴”打开图鉴（每次打开背包时图鉴是收起的，不挡物品栏），样式仿照泰拉瑞亚 1.4 的图鉴（用的是泰拉瑞亚自己的图鉴素材）：最左边按正常路线的先后列出 22 个地区（国王山道、遗忘十字路、苍绿之径……神居），每个地区标出发现了多少种；中间是选中地区（或全部地区）的敌人格子，分成小怪、精英、首领三栏，栏里按一路上碰到的先后排；没见过的是问号，见过的显示空洞骑士猎人日志里的原版立绘，击败过的右上角有星星，首领和精英的边框分别是橙色和紫色；顶部两条进度条显示已发现、已收集的数量。每种敌人归在第一次碰到它的地区（比如小爬虫在国王山道、躯壳哨兵在泪水之城），一路上碰到的先后见 [怪物遭遇顺序.md](怪物遭遇顺序.md)。创造模式存档的图鉴全部解锁。每种能打死的敌人另外各有一半几率掉 2–4 个木材和 2–4 个石块，打几只就够做工作台和熔炉（圣巢里没有树可砍）。难度越高掉落越丰厚，但差距不大：不是必掉的东西，困难的掉率是普通的 1.1 倍、专家 1.2 倍、大师 1.3 倍（最多 100%）；能堆叠的掉落数量上限往上扩一点（按原本的浮动宽度，困难多 15%、专家多 30%、大师多 50%）；钱多掉一些：怪物掉的吉欧困难 1.25 倍、专家 1.5 倍、大师 2 倍。掉的还是同样的东西，数值不变；图鉴里显示的掉率和数量按当前存档的难度算。右边是选中的敌人：立绘放在该区域的地形背景上，名字、类别（普通/精英/首领）和区域标签、危险度星级，四格数值（生命、攻击、防御、击退抗性，都是本 mod 换算后的泰拉瑞亚数值），猎人日志里的描述。敌人第一次出现在屏幕上时解锁这些资料，屏幕下方弹出“发现了新敌人 - 名字”；第一次击败后再解锁猎人笔记和全部掉落（每样东西和几率），弹出“已收集 名字 资料”。

- **怪物刷新**：普通敌人的数量翻倍（每个原版敌人旁边再多一只），死后过一段时间在出生点重新刷出来，不用离开房间。等多久看它有多结实：原版血量 10 以下 30 秒，25 以下 45 秒，50 以下 70 秒，更结实的 100 秒，不会被打断的精英 4 分钟（配置 `EnemyRespawnScale` 是这些时间的倍数）。刷出来前 3 秒，出生点先出现它半透明的虚影提醒你（虚影只是看的，碰不到、踩不上）；你站在出生点旁边（4 格以内）时它会等你走开再刷。出生点被你放的方块或平台占住时，它在附近最近的空位刷出来（站在地上的怪要有能站的地面，贴墙的要有墙），不会刷进方块里卡住；掉出地图、又没被原版的死亡区接住的怪，3 秒后会被收走，到时间在出生点重新刷。多出来的那只放在原版旁边、它所站或所贴的那个面上，要有容得下它身体的空间和同样高度的地面，放不下就不多放，不会塞进墙里。这些会重生的敌人死后尸体 3 秒后淡出消失，不会越堆越多（首领、剧情敌人的尸体照原版保留）。首领、竞技场和斗兽场的波次、剧情和一次性的敌人、苦痛之路和苍绿之径的踩跳平台怪、白色宫殿和神居里的敌人都不受影响。
- **光标和文字**：用泰拉瑞亚的鼠标光标（粉色箭头带浅色描边，亮度和大小来回微微变化；开着智能光标时换成智能光标的样子），代替空洞骑士的光标。界面上的文字完整显示，下半截不会被截掉（有些分辨率下中文字体比文字框高）。鼠标指着东西时的说明文字出现在光标右边、和光标尖端齐平，不会被光标挡住。

- **全屏地图**（M）：泰拉瑞亚式的世界地图，照实际的碰撞体一格一格画出来：地面、建筑（场景里手放的碰撞体）、平台、自己放的各种方块、火把、绳子、挖开的地方，空地上画出水、尖刺、酸水和熔岩，按区域着色。长椅、路灯、门（知道是哪间屋子的会写上，比如斯莱的商店、骨钉大师马托的小屋）、拉杆、升降梯、宝箱、鹿角虫车站、收费机关、被困的幼虫、吉欧石、灵魂图腾、地上的物品、可打碎的墙、温泉、NPC、自己的箱子画成彩色方块，鼠标指着显示是什么（地面会写所在区域，方块写物品名）。和泰拉瑞亚一样走到哪里揭开到哪里：屏幕里看到的格子都记下来，没去过的地方是黑的；揭开的范围跟着存档走（mod 存档旁边的 TerraKnight_slotN.map），有这张地图之前就去过的场景，再进去时整个显示。在科尼法（制图师）或伊瑟达那里买到某片区域的地图后，这片区域的所有房间都直接画在地图上，没去过的也画出来；房间里的生命水晶要亲自走到看见才显示。各场景按门对齐拼成一张整图，和无缝世界里走的一样（空洞骑士的房间在全局上并不完全吻合，有些门两边在地图上会错开一点；门后的房间（商店、屋子、格林剧团的帐篷）画在门旁边的空处，但只在你进到那个房间里时才画出来，免得在德特茅斯的天上看到并不存在的地方；白色宫殿、梦境、电车这些没有门和别处相连的地方画在整张地图的上方）。打开时以自己的头像为中心，滚轮以鼠标处为中心缩放，拖动平移，晶塔图标点击传送，影子的位置画着泰拉瑞亚的死亡标记。原来用空洞骑士地图块拼的旧地图还在，配置里关掉 `Gameplay.TerrariaMap` 就换回去。按 Tab 像泰拉瑞亚一样在三种显示方式之间切换（会记住）：右上角的小地图（泰拉瑞亚的金色边框，边框上的按钮放大、缩小、复原）、半透明盖在画面上的整张地图、不显示；小键盘 +/-（或 = 和 -）缩放当前这种，PageUp/PageDown 调透明度，按住连续变化。打开背包时小地图先收起来，免得挡住装备栏。Tab 用于切换泰拉瑞亚地图的显示方式。
- **传送晶塔**：每把长椅旁边都有一座泰拉瑞亚的传送晶塔，但要先在那把椅子上坐一次才会出现，没解锁的不会提前显示在地图上。长椅旁边地方窄（放不下 3 格宽 4 格高的晶塔）时会放宽距离和高度去找，实在没地方就紧挨着椅子放，保证每把椅子都有。晶塔的样式随区域变（森林、丛林、洞穴、海洋、蘑菇、神圣等），发着光。走到晶塔旁边右键打开全屏地图，点地图上任何一个已解锁晶塔的图标就直接传送过去，从点下到能动大约 1 秒：到达时站在晶塔旁边，从一个快速开合的传送门里走出来，传送门按地区换颜色（苍绿之径绿色、泪水之城蓝色、水晶山峰粉色、格林剧团红色……），站着走出来（坐在长椅上直接传送也一样）；死后重生在那把椅子，椅子用不了（比如没付费的收费长椅）时重生点留在上一把椅子。游戏按名字找重生的长椅时只认已激活的物体，找不到时 mod 改用没激活的同名长椅、晶塔的位置或场景里的门（原版会把人放到场景外无限下坠）。传送很快时原版的淡入事件可能丢掉，mod 会补发，画面照常淡入。不像原版那样要求附近没有敌人、晶塔旁要有 NPC。
- **敌人数值**（以下是大师难度，其他难度见上面“难度”）：以大师模式的蓝史莱姆为基准——空洞骑士最弱的一批敌人（小爬虫、反击蝇、提克提克，原本 8 点血）是 150 点泰拉瑞亚血量，等于两只大师模式蓝史莱姆（25 × 3 × 2）；其他敌人按自己原本的血量同比换算（每点血算 18.75 点），越深的敌人本来就越耐打，比如原本 15 点血的是 282（王国边缘、深渊的再 ×2，终局区域的小怪和精英再 ×5）。**首领的生命和防御直接用它顶替的泰拉瑞亚首领的**，按泰拉瑞亚自己的难度算法（普通 / 专家 / 大师，所有部位加起来）：大师下假骑士是史莱姆王的 3,570，苍绿之径的大黄蜂是克苏鲁之眼的 4,641，残破容器是世纪之花的 53,550，空洞骑士是石巨人的 76,500，神居四位神和辐光是月亮领主的 277,312（奥罗和马托两人分）。一起打的首领平分一个（三只螳螂领主分骷髅王），神居里重打前面阶段的首领换算到终局的强度。全部数值见 [阶段对照.md](阶段对照.md)。区域越深，敌人防御越高（2 / 4 / 8 / 10 / 20 / 30，每次受击减掉一半防御）、越不容易被击退、每个面具换算成的伤害也越高（20 / 30 / 42 / 58 / 76 / 100）。六档区域大致是：国王山道、德特茅斯、十字路 → 苍绿之径、呼啸悬崖 → 真菌荒地、雾之峡谷、王后花园、水晶山峰、水道 → 泪城上层、深巢、古老盆地、蜂巢、安息之地 → 王国边缘、深渊 → 白色宫殿、神居、梦境。
  - 首领和精英：首领的伤害是同区域普通敌人的 2 倍，精英 1.5 倍（它们的弹幕也算；配置项可改），普通敌人的伤害不变。首领和精英不吃击退。精英全程霸体；原版能被打出硬直的首领（大黄蜂、灵魂大师和灵魂暴君、叛徒领主、蜂巢骑士、残破容器和失落近亲、格林和梦魇之王、空洞骑士、骨钉贤者斯莱、纯粹容器）每受到相当于自身生命 2.2% 的伤害，原版的眩晕计数加一次，打法和原版用骨钉时差不多；其余首领全程霸体（原版每一下攻击都给首领攒“眩晕”计数，泰拉瑞亚的武器一秒好几下，按次数计会被连续打断）。每个首领还按体型和打法单独调整：体型大、动作慢、盔甲厚的生命和防御更高，灵活的生命和防御更低、攻击更高，靠召唤物或机关攻击的自身伤害更低（数值见平衡性测试报告）。多阶段首领的生命按阶段分摊：假骑士的盔甲三轮共占 65%、头共占 35%，灵魂大师（和灵魂暴君）两个阶段各占 60% 和 40%。精英是小首领（反击蝇之王、苍白潜伏者、灵魂战士）、独特的敌人（皇家卫兵、老巴德尔等）和原本 70 点血以上的普通敌人（守卫、蜂巢守卫、蘑菇巨人、大哨兵等）。

  - 打中敌人是泰拉瑞亚的效果：伤害数字、血花粒子、泰拉瑞亚的受击和死亡音效，没有空洞骑士的白色斩击闪光和爆散。

- **吉欧石**：武器砍得碎，镐子对准吉欧石点一下也能敲（一下掉一份吉欧，跟骨钉一样）。
- **世界边缘的空气墙**：像泰拉瑞亚地图边上的隐形墙一样，走到（飞到、挖到）一个场景没有接着别的场景的那一边，比如德特茅斯的天上、悬崖的外侧，会被挡在场景边上，不会飞出世界。那一边如果有门（通往不能无缝相接的场景，或者游戏自己的切换），照样能走过去。
- **无缝地图（实验功能，2.3.1 起默认关）**：默认是空洞骑士原版的场景切换（过门读取）。在配置里把 `Gameplay.SeamlessWorldExperimental` 设为 `true` 即可打开：通过左右门、上下门相连的场景拼成一张连续的地图。隔壁场景提前在后台载入，敌人和机关照常活动，就接在门的另一边，看得到、挖得进去。走过门线（或者掉下去、挖过去）时不读取、不黑屏、不停顿，人物保持速度继续走，镜头始终以人物为中心。挖进隔壁的格子会一直保留。上下相接的竖井（比如德特茅斯的井）会把上面场景盖住井道的黑色前景抠开，能一路看到下面场景亮着的井道，下面场景在井道两侧画的砖墙也一直显示到接缝处。走到门线附近时两边场景的调色会渐变，越线时颜色不会突变。空洞骑士里有一种只挡怪、不挡人的隐形墙（Enemy Blocker），原版用来把怪拦在暗道和房间边缘外面；爬虫碰到它不会掉头（爬虫只认地形），会一直顶在那里，飞虫追人会停在半空，像撞上空气墙。这些墙在场景载入时关掉（无缝载入的隔壁场景也一样）。守在门口的那几堵只在门的另一边没有接上场景时留着（防止怪走出世界）；门接上隔壁场景以后也关掉，两边的怪能互相走过去、追过去，不会被卡在接缝上看得见过不来。怪跟到隔壁场景以后，如果那个场景被卸载了，它会停在原地，等那个场景再载入时接着动。首领战、梦境和斗兽场里的照旧全部留着。同一侧的两扇门不在一条线上时（呼啸悬崖入口左边，通往呼啸悬崖的门在最边上，通往鹿角虫巢的门往里三格），靠里那扇门后面的场景不会把靠外那扇门堵住，也不会在走向靠外那扇门时把人交给靠里那扇门后面的场景。只有朝向对得上的门才会拼起来：通往别处房门的出口（比如席奥小屋侧面通到苍绿之径中间的那扇门）不会把那个场景叠到小屋上。站在上下两个场景的接缝上不会来回切换，镜头也不乱飘；越过门线那一刻镜头不会被新场景的镜头锁定区拽走。带 Boss 额外场景的房间、门、长椅传送、死亡复活还是原版的切换方式。隔壁场景在后台载入时，里面的状态机（敌人、机关）分到后面几帧慢慢初始化，载入那一帧一般在 20–40 毫秒以内（国王山道最重，约 70 毫秒）。
- **地形手感**：泰拉瑞亚的自动上台阶（走到一格高的坎会自动迈上去），空洞骑士的斜坡变成台阶后照样能走。场景里手工摆放的地形碰撞（屋顶、墙块、浮空的平台）也并进了格子，挖掉就能过去；一块浮空地形全部挖掉后，它的贴图也一起消失。尖刺和荆棘长在地形上，挖掉的部分连贴图一起没了，碰到挖掉的部分不受伤（悬在空中、没有地形的荆棘照样扎人）。贴着墙往下滑、按住朝墙的方向，经过墙上挖出的洞会直接钻进去。松开跳跃只停止加速，保留已有的上升速度，勾爪拉到一半起跳会带着惯性飞出去，之后还能接云朵瓶二段跳。
- **其他细节**：开局从天上掉下来时镜头停在场景里面；从隔壁无缝走进来的场景里，原版本来关着的状态机保持关着（比如鹿角站里那扇通往黑卵神殿的废门）；还没在任何长椅上休息过就死了，会回到开局出现的地方（国王山道里传送门所在的地面，就像泰拉瑞亚没有床时回到世界出生点；还没坐过的长椅不算复活点，原版的复活点则在德特茅斯入口的高台上，没有长椅也没有晶塔）；铃、拉杆、罐子、藤蔓、可破坏的墙这类要用骨钉打的机关，泰拉瑞亚的所有攻击都能触发（剑、短剑、弹幕、法术、鞭子、悠悠球、召唤物、哨兵，每个机关每 0.25 秒最多算一次），打到尖刺、盔甲、硬壳、可破坏的墙这类原版会“叮”一声的东西时不会像骨钉那样把人弹开（“骨钉”物品照旧会）；从高处落到平台上能稳稳站住（主角用连续碰撞检测），抓钩能勾住平台，首领和精英会穿过玩家放的平台（不会被平台卡住）；电梯、升降台、巡逻敌人这类按坐标工作的机关在拼接后的场景里也对得上；从别的方向挖进原版的隐藏房间时，盖着房间的遮罩会自动揭开。
- **存档**：每个场景挖过、放过的格子，物品栏（包括收藏标记和垃圾桶里的东西），以及解锁了的晶塔，跟着空洞骑士的存档一起保存（坐椅子、退回主菜单时）。
- **多人模式（局域网，IP 直连）**：照泰拉瑞亚的“开服并开始游戏”和“通过IP加入”做的，存档界面左下角“多人模式”进入，详见下面的[多人模式](#多人模式)。
- **泰拉瑞亚设置**：背包右下角“设置”上面多了“泰拉瑞亚设置”：泰拉瑞亚设置菜单里的“自动开火”（按住鼠标所有武器都一直挥、一直射，原版 `Main.SettingsEnabled_AutoReuseAllItems`），敌人血条显示方式，以及泰拉瑞亚控制菜单那样的按键绑定（点一个动作再按新键，Esc 取消，“重置为默认”恢复）。“设置”还是打开空洞骑士自己的设置菜单。
- **50 个存档位**：存档界面标题下面有翻页（“‹ 第 1 / 13 页 ›”，也可以用 PageUp / PageDown 或滚轮），每页是空洞骑士的 4 个存档按钮，按钮上的编号就是存档位号（最后一页是 49、50 号）。存档文件照原版命名（`user5.dat` ... `user50.dat`），打开存档界面时自动翻到上次玩的那一页；创造模式面板列出当前这一页的 4 个存档位。（5 号以后的存档位需要 2.1.0 或更新的版本。）
- **滑墙的摔落计算**：贴墙下滑（攀爬爪、鞋钉）时每一帧都重新计算摔落起点（原版 `WallslideMovement`），滑到底落地时按下滑过程计算摔落伤害。

## 启动

- **玩 mod**：双击空洞骑士游戏目录里的 `泰拉圣巢.bat`。
- **玩原版**：照常从 Steam 启动，不会加载 mod。

启动器的做法是：先打开 BepInEx 的总开关（`doorstop_config.ini` 里的 `enabled`），通过 Steam 启动游戏，游戏起来十秒后再把开关关回去。Doorstop 只在游戏启动那一刻读这个开关，所以中途关掉启动器窗口也不会让 mod 一直开着。

| 螳螂爪 | 攀爬爪 | 按住朝墙的方向慢慢滑下（按下键滑得快），蹬墙跳，滑墙时冒烟尘 |

小骑士自己的跳跃声、蹬墙声、滑墙声、受击声和硬着陆都去掉了，泰拉瑞亚里没有这些。

**骨钉**：开局背包里就有一件“骨钉”（琥珀色的任务物品，和梦之钉一样永久保留，不能卖、扔、丢进垃圾桶，丢了会补回来）。拿在手里时鼠标左键就是空洞骑士原版的骨钉攻击：按住连续挥砍（按原版的攻击间隔），按住 W 上劈、在空中按住 S 下劈，下劈打到尖刺和敌人会弹起来；能格挡（比如安息之地的瑞维克），能拉拉杆、打碎墙；伤害按当前解锁的阶段（阶段 0 到 5 分别是 14、26、42、60、85、125），骨钉匠的每次升级（锋利骨钉、导引骨钉、螺旋骨钉、纯粹骨钉）再提高 25%，纯粹骨钉是两倍；打中敌人时和泰拉瑞亚的武器一样显示伤害数字、能暴击，原版的格挡、下劈弹跳、攒灵魂照常，打中后的后退距离和原版一致。骨钉和梦之钉不出现在制作栏里。瑞维克另外也能用任何武器打散：在他出刀前后打中他就算一次格挡。

**梦之钉**：在原版里拿到梦之钉（先知的梦里）时，背包里会多一件“梦之钉”（琥珀色的任务物品，图标是原版的梦钉）。它会永久保留：不能卖、不能用 T 或右键扔出去、不能扔进垃圾桶；关背包时背包满了，它会挤掉最后一格的普通物品留在背包里；万一不见了（存档里没有、箱子里也没有），一秒后自动补回来。可以放进箱子。把它选在快捷栏上拿在手里，鼠标左键或右键就是空洞骑士的梦钉键，后面全部交给原版：站在地上按住开始蓄力（人物原地站稳），充满后自动挥出原版的梦钉光，打中的敌人冒出它的梦话、给灵魂，进梦境（战士之梦、梦境首领）也是原版梦钉的那一套；按住 S 挥出放下梦之门，按住 W 挥出传送到梦之门（要有梦之门和精华）。挨打会打断蓄力（原版也是）。梦钉的挥砍还会造成近战伤害，按当前解锁的阶段：阶段 0 到 5 分别是 40、75、120、150、200、300，在先知那里觉醒梦之钉后再提高 50%，吃近战伤害加成，能暴击。在守梦人的梦里，用泰拉武器或骨钉把守梦人打伤后，拿着梦之钉按住左键或右键就是原版的聚集，吸收守梦人（屏幕中间会提示）。莫诺蒙和原版一样，要先查看她的水缸、和奎若对话，她才会浮现、能进她的梦。

开局的东西见上面“开局”，其余东西靠德特茅斯的 NPC 商店、制作栏的配方和怪物掉落获得。普通存档里东西要一个一个捡，制作只能用背包里和附近箱子里已有的材料；创造模式存档物品用不完、什么都能直接做（开发配置 `Dev.InfiniteItemsAllSaves` 能让所有存档都这样，默认关）。背包右侧是装备栏：上面三格放头盔、胸甲、护腿，下面五格放饰品，空格里画着该放什么的灰色剪影，左边的盾牌显示总防御。

国王山道尽头那扇大门在新存档里是关着的（原版要从山道里砍 13 下破开）。如果没破门就从别的路（比如悬崖）到了德特茅斯，往回走会被它挡住，从德特茅斯那边看它藏在前景柱子后面；用武器砍 13 下就能破开，和骨钉一样。山道开头那块要从下面往上打碎的木板地面，挥砍打中时只要人在它 3 格以内就算数（原版有个“主角在范围内”的判定，挥砍判定框进出那个范围会把它清掉，所以 mod 放宽到 3 格）。呼啸悬崖入口（国王山道往左上走、穿过黑暗后挡在左边、木板撑着的那面石墙，后面就是第一只小爬虫）贴着墙也能打碎：原版只认墙右边那块受击区，人贴着墙时挥砍只碰得到墙本身，所以打中墙本身也算打中它（每挥一下算一次）。

空洞骑士原版那些在这里已经没用的能力，拿到时不弹出原版的大字说明和按键教学：蛾翼披风、螳螂爪、帝王之翼、水晶之心、暗影披风、复仇之魂/荒芜俯冲/嚎叫幽灵（及升级）、三种骨钉技艺、梦之钉/觉醒/梦之门。有泰拉瑞亚饰品代替的（蛾翼披风→克苏鲁护盾、伊思玛的眼泪→脚蹼等）在给饰品时照常弹泰拉瑞亚的获得提示；猎人日志、国王印记、各种钥匙照原版提示。骨钉大师奥罗、马托、席奥只打招呼，不教骨钉技艺；骨钉匠照原版提供四次升级（苍白矿石加吉欧，吉欧按背包加存钱罐的总数付），每次升级提高“骨钉”物品的伤害。

**建议开一个新存档位来玩。** mod 不会改空洞骑士的存档内容，但在老存档里玩会没有骨钉和技能。卸掉 mod 后老存档一切照旧。

## 多人模式

照泰拉瑞亚的局域网联机做的（端口默认 7777，最多 16 人，可设密码，版本不同、重名、密码错误都会像泰拉瑞亚一样被拒绝）。每个人带着自己选的存档进来：物品、进度、地图都是自己的，在同一个场景（或者无缝地图里相邻的场景）里就能看到彼此、一起打。

**开服**：存档界面左下角“多人模式”→ 填名字（默认用 Steam 昵称）、选外观配色 →“开服并开始游戏”→ 密码（留空则不要密码）、端口、最多人数 →“开始”。顶上会显示“服务器已开启”和本机的局域网地址，然后照常点一个存档进游戏。

**加入**：“多人模式”→“通过IP加入”→ 填开服那台电脑的 IP 地址和端口 →“加入”→（有密码时会问）→ 显示“已连接到 ...”后点一个自己的存档进游戏。

- 开服的电脑第一次开服时 Windows 可能弹出防火墙提示，要勾选允许（专用网络）。不在同一个局域网的话，可以用 Radmin VPN、ZeroTier、Tailscale 这类虚拟局域网，填它给的地址。
- 回到主菜单就退出多人游戏；开服的人退出时服务器关闭（泰拉瑞亚的“本地玩家已离开。开始自动关闭。”），其他人继续单人玩自己的存档。游戏里也可以在“泰拉瑞亚设置”里点“断开连接”。

同步的内容：

- **人物**：位置、跑跳动作、手里的物品和挥砍 / 举枪 / 拿法杖的姿势、盔甲饰品和翅膀、外观配色；头上有名字（有队伍时是队伍颜色），掉血后脚下有血条，死了会碎成三块。全屏地图、小地图上也画着其他人的头像。
- **聊天**：左下角显示最近的消息，说的话在头顶冒出来；进出、开关 PvP、换队伍、死亡都会在聊天里通报（文字都用泰拉瑞亚自己的本地化）。
- **投射物和召唤物**：别人射出的箭、子弹、魔法、悠悠球、召唤物和哨兵都会画在你这边。
- **敌人**：同一个场景里大家看到的是同一批敌人。先进这个场景的玩家的游戏负责敌人的行动（泰拉瑞亚是服务器负责 NPC），其他人那边的敌人照着他那边的位置和动画动，碰到照样受伤；你打中它时，伤害交给负责的玩家结算（击退也是），敌人死了每个人都拿到自己的掉落和吉欧。负责的玩家离开场景后，下一个在场景里的人接手。配置里 `Multiplayer.SyncEnemies` 关掉则每个人打自己的敌人。
- **方块**：挖掉、放下的方块对所有人实时生效，也会记进每个人自己的存档（大家在同一个圣巢里）。
- **PvP**：两个人都开了 PvP、又不在同一队时才能互相伤害，伤害按泰拉瑞亚算（武器伤害 ±15%，暴击翻倍，减一半防御），被其他玩家打死时聊天里显示“X，凶手是 Y 的 Z。”。
- **时间**：昼夜跟着主机走。

还做不到的：敌人只会追负责它的那个玩家（敌人的脚本只在他的游戏里跑）；敌人吐出来的子弹、召唤的小怪只有负责的玩家那边有伤害；首领战的过场和机关、城镇 NPC 的商店、箱子各自独立；没有 Steam 好友邀请，只能填 IP 直连。双方要用同一个版本的泰拉圣巢。

## 原理

- 只运行空洞骑士一个游戏，通过 BepInEx 插件把泰拉瑞亚的系统用原生代码实现进去。
- 泰拉瑞亚的贴图和音效**在运行时从你自己电脑上装的泰拉瑞亚里读取**，mod 本身不带任何泰拉瑞亚素材，所以两款游戏都需要拥有并安装。
- 地形：读取场景原本的 tk2d 碰撞轮廓，栅格化成格子，换成分块的复合碰撞体。挖开的地方用 SpriteMask 把空洞骑士的地面美术抠掉，黑色填充也改由 mod 自己按格子画。
- 无缝地图：进入一个场景后，在后台把它各个门后面的场景叠加载入（真的场景，脚本、敌人都在跑），在任何脚本启动之前把整个场景挪到门的另一边（两个门重合；左右门还会对齐门下的地面）。门线这边归本场景，那边归隔壁。隔壁场景的进场设置（音乐、调色、黑暗程度、区域标题、影子）先压着，玩家真正走进去时才执行；它的 PlayMaker 状态机也先停着，之后每帧拿几毫秒逐个初始化（物品拾取那种为每种物品提前生成提示 UI 的动作在用到时才生成）。走过门线时不走空洞骑士的切场景流程，只是把隔壁设成当前场景（活动场景、场景管理器、地图、存档里的场景名都跟着换），不相邻的场景卸掉，新的邻居在后台接着载入。门、长椅、死亡这类原版切换会先卸掉所有邻居，再按原版流程进新场景。被挪动过的场景里，状态机读写坐标（取位置、设位置、移动到某点、在某点生成物体）时会换算成该场景自己的坐标，所以电梯、巡逻范围这些写死数字的逻辑照常工作。

## 环境要求

- 空洞骑士 Steam 版 1.5.12620（当前正式版，Unity 6）
- 泰拉瑞亚（1.4），默认在同一个 Steam 库里自动查找，找不到时在 `BepInEx/config/com.haoawake.terraknight.cfg` 里填 `TerrariaDir`
- BepInEx 5.4.23.x（win x64）

## 配置

`BepInEx/config/com.haoawake.terraknight.cfg`：

| 配置项 | 说明 |
|---|---|
| `Paths.TerrariaDir` | 泰拉瑞亚目录，留空自动查找 |
| `Gameplay.TerrariaMovement` | 泰拉瑞亚移动手感，关掉保留空洞骑士手感 |
| `Gameplay.CenteredCameraExperimental` | 实验功能，默认关：泰拉瑞亚式镜头，人物每一帧都在画面正中间，不管房间原版的镜头锁定区和场景边缘（和无缝地图一起用才合适）。关着时是空洞骑士原版的镜头 |
| `Gameplay.SeamlessWorldExperimental` | 实验功能，默认关：相连的场景（左右、上下）拼成连续地图、提前载入。关着时是原版的过门读取 |
| `Gameplay.TerrariaMap` | 泰拉瑞亚式世界地图（照碰撞体一格一格画、走到哪里揭开到哪里）；关掉则用空洞骑士地图块拼的旧地图 |

## 开发

```
# 第一次：复制路径配置并改成你的空洞骑士目录
copy LocalPaths.props.example LocalPaths.props

# 编译，dll 会自动复制到 <空洞骑士>/BepInEx/plugins/TerraKnight/
dotnet build src/TerraKnight
```

- `tools/XnbDump`：把泰拉瑞亚的 .xnb 贴图解成 PNG、批量验证贴图和音效解码、渲染物块拼接测试图，不需要启动游戏。
- 自动测试（`Dev.AutoTestSlot`）：用指定的存档位开新档或读档，跳过开场动画，在国王山道里测：
  - 饰品手感（靴子加速、盾冲刺和撞击、云朵瓶二段跳，按泰拉瑞亚的像素/帧记录速度）、攀爬爪滑墙；
  - 智能光标的挖掘顺序、天顶剑的飞剑、抓钩钩住和拉人；

  另外几组单独的测试（`Dev.AutoTestSuite`）：`v10` 测 1.0 的修正（德特茅斯上空的空气墙和左门、缩壳的巴德尔长者吃不吃箭和召唤物、白色宫殿和苍绿之径入口的小地图、门后房间只在里面时画出、首领的泰拉瑞亚数值），`layoutmissing` 只调查地图上还没有位置的场景（不动世界图集），`bossgates` 列出每个首领场地里决定这场战斗打不打的存档记录（`arena` 挑战按钮的依据），`ammoslots` 测弹药栏（找弹药的顺序、捡起时进哪格、只放得进弹药、射箭先用弹药栏），`arena` 测创造模式图鉴里的首领挑战（进场、首领在不在、离开后记录放回原样、梦境和神居打完回到原处），`fixes` 挖空浮空平台看贴图有没有一起消失、在挖空的荆棘上碰一下看会不会受伤、进席奥小屋看有没有把苍绿之径叠进来；`features` 用制作栏和背包的各种点法、对着敌人挥每把剑（剑气、闪光、扣血）、鼠标指着敌人看名字和血量、铺飞毯、在德特茅斯坐椅子解锁晶塔再传送回来；`visual` 越过几处左右和上下的门线，逐帧记录画面亮度变化和镜头偏移，再站在接缝上看会不会来回切换；`tuning` 晶塔（照游戏的顺序：先坐下、过一会儿才设复活点）、敌人强度和首领精英的霸体（和原版受击对照）、刷新和尸体、雷达；`loadout` 切换四套配装、共享饰品和存档迁移；`summon` 召唤杖、仆从、鞭子和标记；`progression` 物品阶段与来源、配方、吉欧零头、敌人翻倍和重生、击杀计入图鉴和掉落、德特茅斯的 NPC 对话、商店买卖和回购，并给城镇、对话框、商店和图鉴截图；`platform`、`ammo`、`weapons`、`accessories` 分别把平台楼梯、全部弹药、新武器和新饰品的数值和泰拉瑞亚原版对照记进日志（比如长枪刺多远、每种额外跳升多高、翅膀爬多高、滑墙多快）。`bossrun` 按正常玩法把世界里的 20 个首领和精英打一遍：从首领房间自己的门进场、走近或走进触发区唤醒、在挑战提示前按上（螳螂领主），然后只用 mod 自己的攻击打（无敌帧照算，打在盔甲上也照打），直到游戏自己记下击杀；记录用时、掉落、尸体上有没有残留血条、打完能不能操作、期间的报错（`bossrun_A+B` 只打其中几个）；`water` 在吸虫之母的水池里落水再跳出来，开打前和它死后各一次。

- 宣传片（`promo/`）：
  - 素材由自动测试录。第一版（30 帧）：`promo` 四个职业各打一个大师模式首领、德特茅斯的井、地图和晶塔、放工作站；`promo2`、`promo3` 灵魂战士、往下挖、苦痛之路、重力球。第二版（50 帧，每帧正好一步物理，动作更顺）：`promoA` 从存档界面开始（点“创造模式”、选存档位、把四个难度挨个指一遍、选大师）、国王山道的传送门开局，然后德特茅斯的 NPC、跟商人对话和买东西、图鉴（打开、指几个、选一个、点“生成”，再把同一条目从普通换到大师看数值和掉率变化）、制作栏、四套配装切换；`promoB` 九个首领（翅膀悬停、保持距离、瞄准平滑过渡，每个职业换没用过的武器）、十字路的掉落、十六把武器轮流用；`promoC` 苦痛之路整间（先按危险物的真实形状做广度优先搜索规划路线，再沿平滑曲线匀速飞完）、月钩、往下挖、重力球、地图点晶塔传送；`promoD` 只录武器；`promoE` 只录地图晶塔；`promoF` 从泪水之城打开地图点晶塔（图标在画面里，传送到达也录下来）。界面操作用测试专用的指针（`TerraCursor.DevDrives`）：光标沿曲线滑到按钮上、停一下再点，悬停效果和真鼠标一样。帧在 `BepInEx/TerraKnight/dev/rec/<片段>/`，压成的片段在 `promo/clips/`（`encode_clips.py`），缩略图在 `promo/sheets/`（`timesheet.py` 出带时间的）。
